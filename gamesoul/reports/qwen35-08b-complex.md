配置：Q4_K_M，纯 CPU，20 个推理线程，4096 上下文，单任务串行，关闭思考，temperature=0，输出上限200 token。

## 工作承诺、低体力与外敌同时冲突

### 输入

```json
{
  "npc": {
    "id": "linlan",
    "name": "林岚",
    "personality": [
      "勤勉",
      "公平",
      "不鲁莽"
    ],
    "health": 35,
    "energy": 12,
    "injured": true
  },
  "known_history": [
    "我今天已搬木材两趟",
    "玩家答应换班但尚未兑现",
    "我答应天黑前修好栅栏"
  ],
  "environment": {
    "weather": "雷暴",
    "enemy_distance_m": 30,
    "enemy_arrival_seconds": 15,
    "safe_shelter_distance_m": 5
  },
  "player_command": "立刻到营地外继续砍树，之后再处理袭击",
  "constraints": [
    "受伤且体力低于20禁止营地外劳动",
    "警报不会消耗资源",
    "警报和进入附近掩体合为一个合法动作"

    "警报并进入掩体",
```
