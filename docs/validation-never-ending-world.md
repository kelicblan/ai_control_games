# 世界永不自动结束验证

2026-10-14。用户最终明确：游戏不应该结束。本记录取代此前“角色死亡仍会失败”的规则。

## 变更

- 不再创建 won/lost 状态，移除自动结算弹窗、重新打开结算入口及胜利音效。
- 每个角色死亡只记录一次事件，保留死亡状态并清除其任务与移动；其他伙伴、昼夜、天气、世界事件、探索和领主继续运行。全员死亡也不会结束世界。
- 只取消涉及死者的待履行承诺、协作和死者发起的交流；保留存活伙伴的承诺与交流，不以角色死亡关闭全部社交。
- 旧胜利/失败存档恢复为可继续的 paused 状态，保留进度、人物死亡和历史，不复活角色或重新开局。加载旧终局快照时清除旧暂停租约，防止结束期间的时间被补算。
- 更新帮助与 README。存档中的 won/lost 类型仅保留作历史格式兼容。

## 证据

- 新增模拟测试最初 5 项失败，实施后通过：单人死亡、全员死亡、跨日与事件、领主移动、存活者承诺、旧 won/lost 恢复。
- 新增 SQLite 测试最初 2 项失败，修复后通过：旧终局档带过期暂停租约时等待手动继续；全员死亡后依然推进、保存和重启恢复。
- 相关 177 项回归通过。
- 最终全量 557/557 通过，结果 `data/never-ending-full.json`；`npm run build` 成功，保留现有大包体警告。
- 最终只读审查未发现实质缺陷。
- 本地世界服务 18081 已重新启动，健康检查 errors=0。浏览器 5173 实际继续旧终局档，已有伙伴死亡；恢复运行后其他伙伴陆续死亡，时间由 26:01 推进到 26:57，仍有暂停、视角与菜单操作，没有结算弹窗。全员死亡的后端推进、领主输入和重启恢复由自动化测试覆盖。
