# 自然景物细节

## 视觉目标

参考最初概念图中茂密、有层次的针叶林、细碎的林下植物和湿润溪流，把这些特征落实到可旋转、缩放和交互的三维营地。近处保留可辨认的枝簇、草叶、蕨叶与表面纹理，远处用完整的树冠轮廓维持林地深度。林缘可以浓密，木材、食物、篝火和休息区之间的路线仍需清楚。

## 几何与风场

十三棵可接近的树仍以地形登记的位置为根，树干有渐细轮廓、纵向起伏和外露根部。近景树使用九层不规则枝条，每条主枝承载四个重叠、下垂的折面枝簇，外缘保留独立针尖；顶梢另有小枝簇覆盖。远树减少针尖数量，保留树冠体积，并避开贯穿远景的溪流走廊。

草由弯曲的窄叶组成，每片生长区域包含六至九个草墩，配合蕨丛、三叶草、小花与落针。生成时读取既有路径距离和物体范围，稀疏处露出土壤。所有活植物共用现有风向、风力与时间；树干、针叶、受光法线和阴影一起弯曲，根部保持稳定。减少动态效果时保留稳定风压并关闭弹性摆动。

## 表面、水与雨

土壤颗粒、树皮沟纹、木纹、岩石矿物与苔痕、帆布织纹由原生程序材质计算，细节随像素尺度过滤，雨水改变颜色和粗糙度。圆润岩体和物体脚下的柔和接触阴影补充体积感。

溪水分为起伏水面、深浅水色、流动细纹和零散泡沫，岸边较缓，中央较快；同一风场驱动横向细波，降雨叠加扩散水环。雨由柔边雨丝、地面及水面涟漪、细小溅滴和檐口滴水组成，落点跟随地面、水面与实际屋面高度。物理地形、天气演算和任务逻辑继续作为权威数据来源。
