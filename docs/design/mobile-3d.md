# CampMind 手机 3D 营地改造

## 用户目标

保留既有松绿、琥珀和奶油色的温暖营地美术，以及阿壮、小米、老周的人设。把网页式上下/左右面板改成专业手机游戏式的全屏场景与浮动 HUD。用 Three.js 创建真正的立体场景，修复人物直穿火堆，提供避障、接触伤害、身体反应、哭喊和针对危险对象的牢骚。

默认竖屏优先，同时支持横屏、桌面、鼠标、键盘和触摸。用户已要求本次改造，直接完成可运行版本和验证。

## 画面与操作

- Three.js 画布占满 `100dvh`，使用带安全区的浮动 HUD，游戏页面不纵向滚动。
- 顶部紧凑资源条、剩余时间、暂停与速度；头像在边缘快捷切人。底部为五个任务按钮，沟通和营地次级选项折叠；地图保持连续可见。
- 保留当前颜色：背景/深面板 `#101f19` / `#172a22`，主文字 `#f4f0df`，强调 `#f3c76a`。沿用已有角色头像、字体和图标。
- 正交或弱透视的斜俯视微缩森林，实际立体树木、岩石、木堆、帐篷、溪流、篝火与角色。柔和阴影、暖火光、可区分角色服饰，角色行走/工作/受伤有动作。
- 人物和地点可点击。点空地发出移动指令；碰到实体目标时停在边缘，危险接触有明确反馈。普通任务优先使用安全路线。
- 模型观察、存档、完整胜负、重开、音效开关保留。技术指标收进观察面板，不占正常游戏 HUD。

## 逻辑边界

Three.js 负责渲染。同步纯状态 `advanceGame(state, dt, policy)` 继续负责逻辑。地面运动采用自有确定性圆形/AABB 扫掠碰撞与导航；不引入异步刚体世界，也不声称实现布娃娃或复杂垂直刚体模拟。

`src/game/terrain.ts` 是静态实体、尺寸和工作站位的单一来源，渲染和碰撞共同读取。现有地图 0–100 坐标映射到 Three.js x/z 平面；NPC 半径 1.1。火堆中心仍为 (51,54)，碰撞半径 3.3，添柴点约 (51,60.2)。帐篷和储物点工作位置移到物体外，多个 NPC 使用独立站位，帮助同伴停在对方体积之外。

新增物理模块处理：路径绕障、连续移动扫掠、滑动、初始重叠纠正、NPC 分离、危险接触。任何到达吸附必须先验证合法，不能直接覆写经过碰撞处理的位置。大型时间增量仍分子步执行。

## 伤害与反应

| 来源 | 接触效果 | 表现 |
| --- | --- | --- |
| 篝火 | 灼伤、健康下降、恐惧升高 | 后退、红色受伤闪烁、惊叫、关于烫伤的抱怨 |
| 荆棘 | 刺伤、健康下降、受伤标记 | 缩身、嘶声、关于荆棘的抱怨 |
| 岩石 | 足够快的撞击才擦伤 | 踉跄、哎哟、关于撞疼的抱怨 |
| 溪水 | 寒冷/打滑、少量健康与体力消耗 | 冷颤、惊叫、关于湿滑的抱怨 |
| 树、帐篷、箱子、同伴 | 阻挡/避让，普通接触不扣血 | 必要时简短让路牢骚 |

每 NPC 有伤害与台词冷却，持续接触不能每帧扣血或排队说话。受伤后先脱离危险，再恢复任务决策。伤害通过现有 health、fear、injured 等进入原有 36 维模型输入，模型不输出路径或碰撞结果。

伤害事件包含类型、对象 ID、强度、台词和 NPC ID。台词是按对象与人格选择的模板，不标称语言模型生成。哭喊采用浏览器本地音频合成，中文牢骚优先使用设备可用中文语音；设备没有中文语音时仍保证声音反馈和中文气泡。声音只能在用户开启/交互后播放，静音、暂停、隐藏页面、重开时停止排队和旧声音。

## 状态与兼容

为 NPC 增加可选的移动与碰撞状态，为事件增加可选的反应信息；序列化校验完整覆盖，旧 v1 存档继续可读。状态不能含 Three.js 对象、可变物理单例或渲染对象。规则对照、本地模型与异常回退继续明确标注。

生产资源包含 Three.js bundle 和新增素材，继续由版本化 Service Worker 缓存。WebGL 不可用或上下文丢失必须显示可恢复的明确状态，不能静默显示黑屏。

## 验收

1. 同一局手机竖屏和横屏均无需滚动，任务可达且不遮住主要人物；原有交互完整可用。
2. Three.js 确实渲染立体物体和人物，摄像机/动画随场景工作；无遗留平面人物叠在火堆上。
3. 跨火堆路线全程不穿入火堆；添柴在火旁完成且不会自伤；多人不会长期重叠/卡住。
4. 火焰、荆棘、岩石、溪水伤害触发来源对应的反馈，冷却有效；静音/暂停与后台不继续叫喊。
5. 本地策略权重和 36 维输入契约保持有效，旧档可加载，新增非法保存数据被拒绝，确定性回放成立。
6. 构建、单元测试和关键 E2E 通过；实际检查手机和桌面截图、控制台、胜负及离线重载。

## 约束与取舍

用户要求真实代码生成 3D 场景，因此场景与角色使用可编辑 Three.js 网格；原有生成头像继续作为 HUD 资源。新概念图用于画面方向，不能替代可玩的渲染画面。本版本是平地上的 3D 生存游戏，不增加跳跃、自由落体或联网语音模型。
