# 今晚别挨饿 — CampMind

## 产品目标
一款完整、精美、可离线运行的中文单屏营地生存游戏，验证真实嵌入式小模型如何控制三名 NPC 的任务与情绪反应。采用 React + TypeScript + Vite，桌面与移动触摸均可玩。无账户、无 API 密钥、无服务端依赖。

首版模型为用合成状态与可解释教师策略训练的专用神经网络，不冒充通用语言模型或微调过的开源 LLM。模型权重随源码发布，训练可复现。模型输出任务与情绪类别，程序负责合法性、移动、动画、资源交易与持续状态。模板台词明确属于表现层。

## 完整玩法
三名队员：阿壮（勇敢）、小米（谨慎）、老周（乐于助人）。单局 240 秒，从午后到黎明；食物、木材、篝火、体力、饥饿、健康、士气、信任构成闭环。采木、采食、添柴、吃饭、休息、互助、回营和探索共八项行为。雨和风带来资源压力，危险导致恐惧或受伤。玩家可选队员、下达工作、表扬/催促、分配食物、全队召回和调整资源优先级。提供暂停、1×/2×/4×、教程、音效、重开和继续存档。

胜利需要到达 240 秒时三名队员都存活、篝火仍亮且全员已回到营地安全圈；任意队员倒下、篝火熄灭，或天亮仍有人在圈外都会失败，结算显示实际任务与生存数据。挑战场景和种子可复现；模型与规则使用同一初始条件、观察契约、动作掩码与天气事件序列，后续状态会随实际决策变化。决策观察面板显示真实输入、模型分数、来源、延迟、行为日志与导出数据。

## 美术与界面
高品质绘本式荒野营地：深松绿外框、奶油色正文、琥珀色交互，暖色篝火与暮色森林，精致手绘地形、帐篷与人物。主屏由顶部资源 HUD、左侧三人队伍、中央占主体的等距营地和底部操作条构成。所有 HUD、文本、按钮为真实组件，地图与人物使用生成的独立美术资源。雨、火星、选中圈和任务进度是程序绘制的功能特效。

## 非目标
首版不包含自然语言聊天、开放世界、多人生存、支付和原生平台打包。政策网络不被描述为聊天 LLM，离线和性能结论基于实际测试。
