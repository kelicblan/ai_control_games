# 天气干扰与真实 NPC 决策

## 用户目标

保留现有手机优先的低多边形森林与营地风格，加入随机风、雨、雷电，让树木、火、帐篷和人物出现一致的环境反应。天气必须成为真实本地 MLP 的输入，让玩家观察到环境变化后的实际任务选择。将地图右侧短溪延伸为贯穿地图的河流。

## 设计

天气由确定性模拟管理，渲染与音效只读取状态。天气阶段包括晴朗、山风、阵雨、雷暴；同种子和同样的人为天气干预产生相同天气时间线。阵风、雨量、云量、风向和雷击时刻保存在统一状态中，暂停会冻结模拟和表现。玩家可以从天气观察窗口主动触发天气，便于重复观察。

雨量和暴露程度决定淋湿速度；帐篷新增与可行走休息区对应的雨棚，提供实际遮蔽和恢复。强风雨加速篝火消耗，帐篷状态随天气变化。雷电使暴露的队员紧张。环境事件可请求重新推理，但不直接替模型指定任务，也不把天气加入动作合法性限制。保留玩家手动移动和携物返程；同任务继续时尽量保留已完成进度。

MLP 在原 36 个输入基础上扩展至 41 个。原索引 14/15 改为连续雨量/风力，新增雷暴风险、湿透程度、暴露程度、雨棚完整度、雨棚距离。同步更新 Python/TypeScript 教师、训练真实权重、导出数值对照样本和模型卡。规则策略与 MLP 使用相同观察和合法动作；不声称 MLP 必然优于规则。台词仍是根据真实动作和环境挑选的模板。

每次决策保存天气快照、触发来源、前一任务、输入特征和实际动作。界面展示事实链路，区分模型、规则、安全回退；不将模板台词当作模型自然语言推理。结构化观察透传至统一策略入口，为后续模型适配提供可序列化输入；本次不接入远程大模型。

## 共享接口

- `GameState.atmosphere`: `windStrength`, `windAngle`, `rainIntensity`, `cloudCover`, `stormRisk`, `lightningAt`, `lightningPoint`, `nextLightningAt`, `revision`。
- `GameState.shelterIntegrity`: 0–100；`Npc.wetness`: 0–100。
- `getWeatherSnapshot(state, npc)` 返回天气类别、风雨/雷暴强度、人物湿透与暴露程度、雨棚完整度和距离。快照使用原始游戏单位，特征生成时再归一化。
- `SHELTER_COVER = { center: { x: 71, y: 72.5 }, half: { x: 6.5, y: 4 } }`。可见雨棚与遮蔽判断共用这个范围。
- `GameCommand` 支持 `type: 'weather'` 与四种天气值；干预写入事件记录。
- `PolicyObservation.context` 包括天气、自己状态、营地物资和同伴，实际观察均携带此数据。

## 河流与场景

保留既有河流的宽度和主碰撞对象标识，将其权威 AABB 延伸到地图与远景两端，地形下凹、水面、石岸、水纹和危险区域统一读取该定义。移走河道里的树。所有工作地点位于西岸，本次不新增过河任务或桥梁。

树木保持合批，通过根部固定的材质变形随风摇摆；阴影同步变形。火苗和火星随同一风向偏移，雨量抑制火势。帐篷布料和雨棚有固定支点、飘动与雨水表现。雨、风和雷电使用有数量上限的缓冲区，避免每棵树独立绘制。NPC 姿态读取同一环境值；引擎继续控制位置和碰撞。

## 兼容与验证

旧 v1 存档补齐新增状态；保留原始 36 维历史记录并标明旧版，不能伪造新增输入。新 41 维决策严格验证。河道扩展可能让旧位置落入水中或隔在东岸；迁移根据共享河道边界、人物半径和实际寻路连通性，只修复受影响的位置与路线目标，并记一条信息事件。未受影响的路线、携带物资、任务进度和历史观察值继续保留。生产离线资源清单包含更新后的权重。

验证涵盖天气确定性、暂停、遮蔽与淋湿、真实再决策、手动/返程保护、旧存档与恶意字段、真实权重对照、河流两端危险区域、全套测试、生产构建、手机与桌面浏览器交互、静音/暂停后音频清理。
