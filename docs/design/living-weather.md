# 连续天气、营地环境与真实 NPC 决策

## 用户目标

保留现有手机优先的低多边形森林、营地、人物和交互，让贯穿地图的河流、风中树木、火烟与环境声遵循一致的方向和强弱关系。天气继续作为真实本地 MLP 的输入，让玩家同时观察环境表现与伙伴实际任务选择。

## 设计

天气由确定性模拟管理，渲染与音效只读取状态。天气阶段包括晴朗、山风、阵雨、雷暴；同种子和同样的人为天气干预产生相同天气时间线。阵风、雨量、云量、风向和雷击时刻保存在统一状态中，暂停会冻结模拟和表现。玩家可以从天气观察窗口主动触发天气，便于重复观察。

切换天气时，风力逐步接近新的目标，风向沿最短角度连续转动并限制转速。`windStrength` 已包含阵风，各表现模块直接使用这个当前值。`windAngle` 表示**风吹去的方向**：`cos(angle)` 对应世界 X 轴向东，`sin(angle)` 对应世界 Z 轴向南。界面写明「风吹向……」，罗盘固定地图北在上方；相机旋转不改变地图方位。

雨量和暴露程度决定淋湿速度；帐篷新增与可行走休息区对应的雨棚，提供实际遮蔽和恢复。强风雨加速篝火消耗，帐篷状态随天气变化。雷电使暴露的队员紧张。环境事件可请求重新推理，但不直接替模型指定任务，也不把天气加入动作合法性限制。保留玩家手动移动和携物返程；同任务继续时尽量保留已完成进度。

既有天气决策模型在原 36 个输入基础上扩展至 41 个。原索引 14/15 使用连续雨量/风力，新增雷暴风险、湿透程度、暴露程度、雨棚完整度、雨棚距离；Python/TypeScript 教师、训练权重、数值对照样本和模型卡已同步。规则策略与 MLP 使用相同观察和合法动作；不声称 MLP 必然优于规则。台词仍是根据真实动作和环境挑选的模板。本轮环境表现和声音增强不改动模型结构、特征顺序或权重。

每次决策保存天气快照、触发来源、前一任务、输入特征和实际动作。界面展示事实链路，区分模型、规则、安全回退；不将模板台词当作模型自然语言推理。结构化观察透传至统一策略入口，为后续模型适配提供可序列化输入；本次不接入远程大模型。

## 共享接口

- `GameState.atmosphere`: `windStrength`, `windAngle`, `rainIntensity`, `cloudCover`, `stormRisk`, `lightningAt`, `lightningPoint`, `nextLightningAt`, `revision`。
- `GameState.shelterIntegrity`: 0–100；`Npc.wetness`: 0–100。
- `getWeatherSnapshot(state, npc)` 返回天气类别、风雨/雷暴强度、人物湿透与暴露程度、雨棚完整度和距离。快照使用原始游戏单位，特征生成时再归一化。
- `SHELTER_COVER = { center: { x: 71, y: 72.5 }, half: { x: 6.5, y: 4 } }`。可见雨棚与遮蔽判断共用这个范围。
- `GameCommand` 支持 `type: 'weather'` 与四种天气值；干预写入事件记录。
- `PolicyObservation.context` 包括天气、自己状态、营地物资和同伴，实际观察均携带此数据。

## 河流与场景

既有河道范围已贯穿地图与远景两端，地形下凹、水面、石岸、水纹和危险区域统一读取该定义。河道内没有树，所有工作地点位于西岸。本轮在这一范围内增加连续水流表现。

| 对象 | 物理表现 |
| --- | --- |
| 河流 | 主流始终沿世界 +Z 向南。水纹与泡沫使用同一流速剖面，河心快、近岸慢；风增加短波，雨增加细密扰动，主流不随风反转。水面法线和高光随波纹更新，交替淡化的流动纹理避免长期剪切累积。 |
| 树木 | 保持合批，树根固定，分段树干沿高度弯曲，树冠随局部斜率倾斜。每棵树具有不同的弹性摆动相位；可见几何、光照法线和两类阴影使用同一变形。 |
| 篝火 | 火焰底部留在木柴上，上端顺风弯曲；轻烟和火星先受浮力上升，再向下风偏移。雨会压低火焰、减少火星并增加少量蒸汽。实际火势降低时，火光、炭火、烟柱和可见粒子一起减弱。 |
| 布料与人物 | 帐篷和雨棚保留支点、缝线与雨水表现，布面随统一风向鼓动。NPC 姿态读取相同环境值，位置、任务和碰撞继续由引擎决定。 |

这些属于**轻量物理表现近似**：河流使用给定速度场，树木和布料使用受约束的形变，烟、雨和火星使用有限生命周期轨迹。完整流体、柔体或刚体动力学求解不在范围内。水面和树木主要在 GPU 更新，泡沫、烟与天气粒子有固定数量上限，避免逐帧遍历大量独立树木。

水面、树形和烟火轨迹由游戏时间与当前天气计算；飘叶和风线只积分新经过的模拟时间，在换世界或时间倒退时重置漂移。它们不消耗游戏随机数，暂停时保持相位与位置。系统开启「减弱动态效果」时，保留稳态风压与天气强弱，停止持续摆动、流动和粒子动画。

## 本地环境声

浏览器通过 Web Audio 在本地生成并复用短音频纹理，不下载环境录音或调用远程合成服务。五个持续声部各自随真实状态混音：

| 声部 | 响应 |
| --- | --- |
| 风声 | 随风力改变强弱和音色，从上风侧传来。 |
| 树叶沙沙声 | 随风增强，提供区别于低沉风声的高频摩擦感。 |
| 雨声 | 随雨量改变响度和密度感。 |
| 溪水声 | 使用共享河道范围计算距离，选中伙伴越靠近水边越清楚。 |
| 篝火声 | 随伙伴到篝火的距离、实际火势和雨量变化，火熄灭后停止噼啪声。 |

聆听位置取**选中的存活伙伴**，立体声左右依据**当前相机的右方向**。移动伙伴、切换选择或旋转镜头后，距离和左右声像相应更新；设备不支持立体声定位时保留单声道播放。

雷声是由同次闪电触发的独立事件，分为短促雷击和较长滚雷。到达延迟、响度、左右方向及尾音依据雷击位置与聆听伙伴的距离估算；仅雷声采用微缩地图的声学比例，并随模拟速度调整等待时间。这是简化的距离传播表现，未求解地形遮挡、反射或完整声场。

声音默认关闭，只有用户点击开关后才尝试解锁音频设备；开启失败会显示可重试的提示。静音、暂停、进入后台、重开或音频设备中断时，释放持续声部并取消尚未到达的雷声，恢复后不补播旧雷击。角色叫声与设备本地中文语音沿用同一停止规则。

## 开启与观察

1. 开始旅程，点击顶部天气标签打开「风雨中的营地」，可选择「吹起山风」或「唤来雷暴」。风力和风向会逐渐变化，河流继续向地图南方流动。
2. 点击窗口中的「听见这片营地」，或顶部「音效关」。关闭窗口，回到运行中的场景，聆听五层环境声。
3. 选中不同伙伴、安排他们靠近溪边或篝火，再旋转镜头，比较声音远近和左右方向。天气罗盘始终以地图北向为准。
4. 打开「决策观察」，检查同次环境变化后的天气快照、前一任务、实际选择与模型／规则来源。

## 兼容与验证

旧 v1 存档补齐新增状态；保留原始 36 维历史记录并标明旧版，不能伪造新增输入。新 41 维决策严格验证。河道扩展可能让旧位置落入水中或隔在东岸；迁移根据共享河道边界、人物半径和实际寻路连通性，只修复受影响的位置与路线目标，并记一条信息事件。未受影响的路线、携带物资、任务进度和历史观察值继续保留。生产离线资源清单包含现有模型权重与更新后的场景代码。

验证重点包括天气确定性与连续转向、暂停和回看、遮蔽与淋湿、真实再决策、手动/返程保护、旧存档、真实权重对照、河流正向与岸边减速、树根固定和阴影一致、低火减光，以及声音定位、距离雷声和中断清理。具体运行结果、生产构建与手机／桌面交互记录见[验证记录](../validation.md)；回合表现与样本限制见[评估说明](../evaluation.md)。

模型加载时始终进行 SHA-256 完整性校验，缺少 WebCrypto 的普通 HTTP 环境使用纯 JavaScript 回退。生产 Service Worker 离线缓存仍需 HTTPS 或 localhost；这项部署要求与模型能否校验、推理分别处理。
