# 连续世界地图：实现与验收说明

日期：2026-10-13。基础版本：main 的 3db1c926。开发分支：feat/continuous-world-map。

## 本版可使用的功能

初始营地中心为世界坐标 (50,55)，半径 1000 米默认已探索，之外黑雾。世界坐标不再限制在 0..100。每个地图块 128 米，支持负坐标；渲染窗口最多保留 169 个块，不一次性加载整个已知世界。数值校验上限是浮点安全保护，不是固定玩法边界。

主场景拖动默认平移；滚轮/双指缩放，辅助鼠标操作/双指旋转。鹰眼显示北向、地形、营地和人物、实际相机视野，可以展开、折叠、缩放地图和定位相机。鹰眼点击只移动镜头；选中人物后点击主场景地面才下达移动命令。回营按钮只移动镜头，跟随按钮跟随选中角色，手动拖动取消跟随。

角色移动实际推进探索（视野半径 70 米、探索格 16 米），相机浏览和暂停不能揭雾。模拟时钟与渲染加载窗口独立，镜头离开营地时仍继续进行工作、消耗、天气与人物决策。

外围按世界种子生成分片森林、草地、北侧山地和连续河道。渲染、树干碰撞、坡度判定与跨河桥使用同一地理配置。地图块之间的高度采样、河道位置不依赖加载顺序。跨河使用实际桥面，远距离路线采用限预算分段 A*，不能因为寻路预算耗尽就直接穿墙。

初始住宅是领主茅草房和伙伴长屋。长屋有五个床位与独立站位，门洞和墙壁共享物理布局。两间房都能避雨；选中屋内角色时隐藏屋顶方便观察，但雨滴碰撞仍保留实体屋顶。

## 可复用边界

- packages/world-core：确定性随机场、世界/分块坐标、探索位图、加载窗口、通用有预算寻路；不依赖 React、Three.js 或营地人物。
- packages/world-three：可平移相机、原点重定位、分块地形/植被/桥/迷雾和通用茅草房渲染。
- packages/world-ui：鹰眼地图。只有相机回调，没有人物移动和探索写入接口。
- src/games/camp/world：游戏种子、起始区域、房屋配置、世界存档状态和营地寻路适配。
- src/games/camp/simulation：游戏规则、任务与人物状态，保留现有 MLP 特征版本和社会行为。

## 世界状态与存档

GameState.world 保存 schemaVersion、revision 和 exploration。探索快照保存种子、生成器版本、初始已知圆与新增探索位，不保存全部程序化地形网格。

旧存档缺少 world 时迁移为同种子的初始世界，人物位置不再被错误裁回 0..100。已存在的河东岸角色保留位置，通过桥连接营地。未知的未来世界版本会被拒绝读取并保留原始存档，不能静默覆盖生成。

渲染原点按 1024 米重定位，地图、人物、碰撞与存档保持原世界坐标。雨滴射线查询显式转换渲染原点，防止镜头远移后屋顶挡雨位置偏移。

## 已执行的自动化验证

本地及 GitHub Actions 均通过 32 个测试文件、430 项单元测试；NPC 公共包依赖检查和生产构建通过。覆盖负坐标、初始探索边界、真实模拟揭雾、保存恢复、未来存档保护、限定加载预算、桥面通行、树干/坡度阻挡、所有住宅床位可达、剖视屋顶仍挡雨以及原点重定位后的雨滴碰撞。

新增 e2e/world.spec.ts，在桌面 1440x1000 和手机视口 390x844 检查实际浏览器加载、主视图平移、鹰眼展开/键盘定位、黑雾、回营、跟随及布局溢出，并输出截图。浏览器执行结论以对应 Actions 日志为准，不把构建通过冒充视觉验收。

本地 Chromium 被环境管理员策略禁止导航，未更改该策略；浏览器验证使用项目 GitHub Actions 的独立运行器。可选 MiniMind GGUF 不属于地图验收，世界用例只禁用其下载，没有声称验证真实 GGUF 推理。

## 仍然存在的限制

1. 本版保留原有 240 秒生存验证局，不是无限时长的沙盒模式。地图可扩展不等于游戏回合时长已改造。
2. 现有采集/探索行为仍以营地任务体系为主。手动人物移动与探索已接入连续世界，完整的自主边疆远征、区域任务与动态资源点分配尚未实现。
3. 外围地形与基础植被是程序化低细节版本，未达到手工美术区域的精细程度。风雨灯光联动保留，但精细雨滴粒子仍主要围绕营地，远处天气粒子流式覆盖尚未完成。
4. 保存了探索记录与生成器版本，但尚未增加砍树、资源耗尽、新建建筑等世界修改增量存档；旧游戏也没有完整对应编辑玩法。
5. 尚未完成真实 Android/iOS 设备帧率、极远距离持续探索以及长期存档体积测试。新增探索会重建当前有限地形窗口，后续可改为增量更新。
6. 构建仍有大于 500 kB 的 JavaScript 分块警告。npm ci 的现有依赖审计报告另有 2 项 critical、1 项 moderate，需单独分析修复；本轮没有通过强制升级依赖掩盖风险。

## 本地运行

```sh
git fetch origin
git switch feat/continuous-world-map
npm ci
npm run dev
```

首次本地缺少该分支时，使用 git switch --track origin/feat/continuous-world-map。已经有未提交修改时先保留自己的工作，不使用强制 checkout/reset。
