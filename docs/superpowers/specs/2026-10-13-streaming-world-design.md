# 连续世界地图升级设计

状态：用户已确认，2026-10-13 继续实施。

## 目标与边界
将固定营地沙盘升级为可继续探索的世界。营地是出生地点而不是地图边界；保留已有 NPC、模型决策、对话、天气和紧凑手机界面。通用地图能力与营地游戏规则分目录，关键逻辑使用中文注释。

## 世界与探索
- 地图块尺寸 128 米；支持负坐标，按视野加载与卸载，不一次绘制整个世界。
- 初始已探索范围为营地半径 1000 米，之外黑雾。移动相机不能揭雾；角色到达才增加探索记录。
- 区分未探索、已探索但不在视野中、当前可见。场景、地面拾取、标签、小地图共用探索数据。
- 同一种子与生成版本应生成相同地形。世界存档保留探索、种子及生成版本，旧存档迁移，不重置 NPC。
- 相机加载和模拟相互独立。营地、出发中的 NPC 不因镜头离开停止模拟。

## 地形与营地
手工初始营地加确定性外围生成；成片森林、草地、起伏山地和连续河流。河道、地形、水面、碰撞及导航使用同一数据源，跨块不能断裂。北侧远山，西侧林地，东侧草地与河流，道路连接主要工作区。

营地可扩建范围约 120×100 米，保留集中的生活区。一栋领主茅草屋、一栋五名 NPC 共用的茅草长屋。屋内有固定床位，门与墙体可通行判定正确，屋顶能遮雨，屋内人物可通过隐藏屋顶观察。篝火避开交通交叉点。

## 相机与地图 UI
主键/单指拖动平移，辅助键/旋转模式旋转，滚轮/捏合缩放；支持回营地与跟随选中 NPC，手动平移退出跟随。取消原 0–100 的拾取裁剪，点击匹配地形高度。

鹰眼地图位于右上角，可折叠、可展开，北朝上；显示地貌、河流、营地、己方 NPC、迷雾和视野范围。点击地图仅定位镜头，探索/前往必须明确下达。大地图独立拖动和缩放，不使用全世界探索百分比。

## 技术约束与验收
不替换 React/TypeScript/Three.js 技术栈，不删除既有测试。通用能力不引用营地人物或任务名。绘制资源必须卸载释放。坐标转换、负块坐标、生成稳定性、探索持久化、相机不揭雾、越过旧边界、房屋门口和跨块导航均需测试。验证区分单测、构建与真实浏览器结果，不以截图代替玩法验收。
