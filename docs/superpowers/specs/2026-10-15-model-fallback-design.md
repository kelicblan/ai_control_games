# 常驻 MiniMind3 与可选优先模型

用户已确认：页面启动立即后台准备 MiniMind3，SHA 校验后保存 CacheStorage；刷新复用权重缓存但重新初始化 WASM。MiniMind3 从切换选项移出，与本机、远程优先模型独立存活。没有优先模型、优先模型加载中或异常时使用 MiniMind3；它不可用时保留即时回应。模型只生成台词，不改变模拟世界。

## 生命周期与路由

- ModelManager 分别保存 MiniMind3 与优先模型进度。selectedId 保留 minimind3 作为兼容的“无优先模型”值，catalog 不再包含该项。activeId 表示当前真实可用模型。
- 启动 bootstrap 并行预热 MiniMind3、恢复已选模型。切换只取消/卸载优先模型，不卸载 MiniMind3。MiniMind3 首次加载最多自动重试两次；失败后手动重试。
- 优先模型初始化/生成失败触发冷却，30 秒后允许重新准备；生成同次请求尝试 MiniMind3。已取消、旧选择、busy/skipped 不触发模型故障恢复。取消和迟到响应保持隔离。
- MiniMind3 重启与优先模型请求使用独立取消域；界面显示两个进度和实际来源。不能把 ready 的兜底掩盖为优先模型成功。
- 有效权重缓存优先于在线清单检查，清单暂不可用不阻断热启动。仅缺失或损坏缓存时检查清单并下载。根据真实推理耗时，营地整体请求期限为 40 秒，覆盖 5 秒优先请求与 MiniMind3 原有 30 秒推理窗口；即时模板和模拟始终不等待。

## 远程配置

首版 OpenAI 兼容 chat/completions，支持名称、HTTP(S) Base URL、model、API Key，增删改、连接测试。用户后续要求覆盖初版会话密钥方案：配置及 API Key 按已有玩家 cookie 身份保存到 SQLite；密钥 AES-256-GCM 加密，列表不回传，仅服务端调用时读取。刷新和服务重启继续有效。请求通过 Node/Vite 同源游戏服务转发，不跟随跳转，限制输入/响应体积与超时，不把提供商错误原文透传给用户。公开部署时桥拒绝私有/保留地址，防止成为内网代理。详见 docs/game-model-settings.md 和 docs/validation-model-storage.md。

## 验收

单元测试覆盖双生命周期、加载和生成故障回退、冷却恢复、取消/迟到响应、有限重试、配置非敏感持久化、远程协议/超时/错误/地址边界。浏览器覆盖开局前真实权重加载、刷新缓存复用、设置配置与回退、桌面界面。全套测试、构建、NPC 包边界通过；无真实远程凭据时明确远程真实服务未验证，使用受控兼容服务验证请求链。
