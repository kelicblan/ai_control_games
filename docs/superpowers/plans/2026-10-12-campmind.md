# CampMind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver a polished playable survival game with a genuine local NPC neural policy in the requested GitHub repository.

**Architecture:** A deterministic simulation consumes a shared PolicyFunction; the local neural network and fair teacher baseline share observations and legal actions. React renders a generated-art map and native controls. Persistence and a service worker support offline replay.

**Tech Stack:** React, TypeScript, Vite, Vitest, NumPy training, local Float32 inference.

**Spec:** docs/design/game-spec.md

## Global Constraints
- All player-facing copy is Chinese.
- No API keys, network inference or simulated model results.
- One shared model, three independent NPC states; finite legal action IDs.
- Model limitations and teacher imitation are explicit.
- Generated raster art; native interactive HUD; responsive desktop/mobile.
- Existing README-only repository is preserved through normal Git history.

## Review Focus
- A changed seed, reload or mode cannot revive stale decisions or corrupt state.
- Resource starvation and simultaneous jobs never spend negative inventory.
- Policy errors or invalid outputs are visibly marked fallback and remain executable.
- Pausing and hidden tabs cannot advance simulation unexpectedly.
- Victory, failure and restart complete without locking the interface.
