# 一寨之主 32km 二维地图第一阶段实施计划

> 执行：本轮直接实施已获用户确认的地图方案；采用隔离功能分支，不覆盖正式入口和旧存档。

**目标：** 建立可以在 Unity 中实际探索的二维像素地图首版，而非将概念图贴作背景。
**架构：** 无第三方依赖的 Node 地图宿主是地形、碰撞、资源与位置的唯一来源；Unity 只消费分块快照和提交输入。新地图先走独立 SQLite 验收存档，后续接入原有 VillageRuntime 的生产、社会化及 MLP，不使用假 NPC 或伪造模型输出冒充联调成功。
**技术：** Node 24+ / node:sqlite、Unity 6000.3.26f1、Input System、正交摄像机、SpriteRenderer、最近邻纹理。
**设计依据：** 用户确认的《一寨之主·超大初始区域规划》：32km×32km、十人村寨、五间村民屋、寨主议事厅、工坊、储物间、清晰南寨门、西北金矿与可扩展边缘。

## 约束
- 地图坐标单位米，x向东、y向南。范围[0,32000)，不通过夸大村寨与树林实现虚假尺度。
- 村寨180×160米，五间双人屋＋寨主住所。门洞12米，瞭望塔位于旁边，不堵门。
- 地图按128米分块；单块64×64地表格，格长2米。资源、建筑是独立实体。
- 木/石/纤维/食物开局可达；金矿为一个远程地标。河流、桥、道路与碰撞同源。
- 初始边界不是永久围墙；生成坐标与资源ID不随访问顺序变化。扩展不得重编号既有节点。
- 不改旧规则、MLP权重、旧存档、Windows网络策略，不把地图验收库存当正式游戏库存。
- 使用原创程序化像素首版素材；不将参考截图直接当精灵资产或宣称达到最终美术质量。
