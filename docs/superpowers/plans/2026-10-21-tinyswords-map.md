# TinySwords 原规划地图实施计划

**Goal:** 将已确认的原规划村寨与区域布局落实为可运行的 Unity 二维地图，使用 TinySwords 自然素材并补齐木寨设施。

**Architecture:** Node 地图继续权威管理地形、位置、碰撞和采集；Unity 使用同一地形快照拼接正式图集。通过 Editor 生成带显式引用的 Resources 素材目录，运行时不依赖 AssetDatabase。村寨增加固定装饰层，环境装饰不冒充可采集资源或 NPC。

**Tech Stack:** Unity 6 / C#、TinySwords PNG、Node 24、SQLite。

## 已确认设计与边界
- 原图空间关系：北侧议事厅、五间民居围绕中央公共空间、南侧仓储与工坊、南寨门、北侧村外溪流与桥；森林、岩石、灌木构成村外边界。
- 32km 世界、八座功能建筑、真实碰撞和开局资源保留。补充木寨外观，不能用西式城堡直接冒充中式议事厅。
- 保护工作区既有 Unity 设置修改和所有旧存档；不清档，不伪造 NPC/MLP/生产迁移。
- 优先原生可操作画面；代码、构建、视觉证据分别记录。
