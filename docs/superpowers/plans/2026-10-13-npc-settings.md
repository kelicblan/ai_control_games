# NPC 初始值设置实施计划

**Goal:** 提供可复用的逐角色设置界面与数据库接口，并在营地新开局应用初始值。
**Architecture:** 通用配置核心 + 通用 React 编辑器 + IndexedDB/SQLite 适配 + 营地字段及执行映射。
**Spec:** ../specs/2026-10-13-npc-settings-design.md

## 实施顺序
1. 先写校验和 SQLite 合同测试；实现严格版本、字段和乐观锁验证。
2. 接入营地初始快照、动态人格和工作技能；存档只接受经过验证的快照，兼容缺省旧档。
3. 实现通用表单、浏览器仓储和营地页面入口；新开局读取配置，继续存档不受影响。
4. 添加玩法与浏览器回归，独立编译通用包；核对差异、中文注释与文档。

## 特别检查
- 负数、空输入、未知字段及未来版本不得悄悄保存。
- 模板变化不能修改已运行角色或清除心智记忆。
- 默认技能不得改变旧版平衡，送货不能提前结算。
- 数据库失败不能声称已保存；并发编辑必须提示冲突。
- 通用目录不能引用营地、React（核心）或浏览器（核心）。
