# 游戏运行记录重置

目标：在游戏设置中增加带二次确认的重置按钮，清除当前玩家的 NPC、玩家和世界运行记录，创建初始世界。保留模型选择和角色初始配置；不影响其他玩家。

1. 增加 reset 世界操作。服务端采用默认种子 64138、悠然露营、标准场景和模型决策，应用已保存的角色初始配置。新世界从零开始，速度为 1。
2. SQLite 在同一事务内删除当前玩家的全部快照（包括隔离的损坏快照）、旧操作记录，保存新世界与本次操作标识。保留递增修订，防止旧标签页覆盖新世界；重试同一操作不得再次重置。失败必须回滚。
3. 前端在重置期间停止旧对话任务，成功后清除对话缓存与统计、旧浏览器存档和视角记录，重建场景并关闭设置。失败留在面板并显示错误。配置读取失败时不提交重置。
4. 验收：历史/隔离快照与旧操作清空、玩家隔离、幂等重试、陈旧请求拒绝、事务失败回滚、服务重启后不恢复旧记录；桌面浏览器验证取消、确认、失败和刷新流程。

验证命令：`npx vitest run tests/world-reset.test.ts tests/world.test.ts tests/world-client.test.ts tests/dialogue.test.ts tests/camera-memory.test.ts`、`npm test`、`npm run build`、`npx playwright test e2e/game-reset.spec.ts`。
