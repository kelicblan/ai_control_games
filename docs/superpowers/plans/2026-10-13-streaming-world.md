# 连续世界地图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现可扩展世界、探索迷雾、自由镜头、鹰眼地图与两间茅草房。

**Architecture:** 通用世界模块负责坐标、确定性地形、分块加载、探索序列化；营地适配负责初始布局、NPC 与任务。Three.js 场景消费地图数据，React 地图 UI 使用同一数据源。

**Tech Stack:** 现有 TypeScript、React、Three.js、Vitest、Playwright。

**Spec:** docs/superpowers/specs/2026-10-13-streaming-world-design.md

## Global Constraints
- 128 米地图块，初始已探索半径 1000 米；不裁剪回旧的 0–100 范围。
- 相机不得改变探索；NPC 模拟不得依赖已绘制块。
- 保留现有玩法与旧存档，通用模块不引用营地人物，关键代码中文注释。
- 使用独立功能分支，不直接覆盖 main。

## Review Focus
- 负坐标边界与地形接缝。
- 镜头拖入黑雾泄露标签或实例树木。
- 读旧存档、损坏探索记录、刷新后重新随机生成。
- NPC 远行或处于屋内导致寻路、遮雨和休息失效。
- 手机手势、地图面板事件穿透和反复流式加载导致资源泄漏。

## Task 1：读取基线并建立测试
- [ ] 阅读场景、相机、营地地形、物理、状态与存档代码，以及既有测试。
- [ ] 运行基线测试，记录失败与网络/环境限制。
- [ ] 先添加覆盖新行为的失败测试，再实施对应模块。

## Task 2：通用世界数据与探索
- [ ] 实现分块坐标、确定性生成、地形采样、河道、探索记录及持久化验证。
- [ ] 测试负坐标、种子复现、跨块连续、初始 1 公里与相机不揭雾。

## Task 3：营地模拟适配
- [ ] 接入世界状态、保存迁移、角色探索、世界位置与局部寻路；移除旧边界裁剪。
- [ ] 保留原策略观测字段，远行目标与已有动作兼容。
- [ ] 布置两间茅草房，碰撞、门口、床位与遮雨共用布局数据。

## Task 4：Three.js 表现与输入
- [ ] 分块地形与实例植被、连续河流、黑雾、资源卸载。
- [ ] 自由平移、旋转、跟随、回营、地形拾取与视野投影。
- [ ] 茅草房与内部床位；已探索和当前可见显示一致。

## Task 5：鹰眼地图与回归
- [ ] 可折叠鹰眼与展开地图，视野轮廓、定位和显式探索命令。
- [ ] 运行完整单测、NPC 校验、TypeScript 与生产构建，执行浏览器验证。
- [ ] 审查差异，提交功能分支与 PR，报告已验证和未完成项。
