# 触发调试窗口实施计划

用户已确认 MLP 行为决策与 NPC 对话触发日志方案。

1. 新增独立 SQLite 日志表和查询模块：追加保存完整结构化事实，按 owner/world/kind 索引，界面固定最新100条；重启保留，重置不删除历史。
2. 在 VillageRuntime 的真实策略决策入口、工作对话依据入口、社会模型请求和发布校验入口记录；不记录密钥、凭据或完整模型提示。
3. 经现有受保护 pixel API 读取当前玩家当前世界的最新100条，只读查询不推进世界。
4. Unity 右侧增加 MLP触发 / 对话触发按钮，共用右下调试窗，匹配世界频道样式，固定字号、滚动、关闭、状态和保存路径；只在打开时拉取。
5. 验证追加/100条/所有者和世界隔离/重启持久化、真实触发链路、TypeScript、Unity编译与窗口截图；最后正式入口启动当前包。

日志中观测条件与模型选择分开陈述，不推断神经网络内部因果。记录执行拒绝和模型失败，不将生成成功等同于已发言。
