日期：2026-10-15。范围对应 `performance-audit-2026-10-15.md` 第一批；当前工作区还有其他未提交改动，本记录仅说明本批修改和实际验证。

## 已实现

| 路径 | 修改 | 边界 |
| --- | --- | --- |
| `src/scene/characters.ts`、`campScene.ts` | 水平距离决定插值/传送；沿渲染后的水平位置采样高度 | 高地不再因为高度差误触发传送；保留碰撞与大距离跳转规则 |
| `packages/world-core/src/index.ts` | 探索同步按实际位图差异更新版本；支持撤销探索；按地块及邻接探索签名失效 | 不修改权威模拟、存档格式和探索规则 |
| `packages/world-three/src/terrain.ts` | 保留未受影响地块；缩放切换树木细节时不清空地面；最近地块优先分帧生成 | 游戏场景每帧最多 2 块、3ms 软预算；单块生成不可抢占，可能超出软预算 |
| `packages/world-ui/src/minimapRaster.ts`、`minimap.ts` | 世界坐标对齐的地形像素缓存、64 个缓存块上限、130×130 复用缓冲区、128×128 子像素裁剪 | 每次最多 1024 次新采样、采样累计 3ms 软预算；整个像素循环不保证 3ms；未知区域不采样、不泄漏，撤销探索立即遮盖 |
| `src/scene/frameProfile.ts`、`campScene.ts` | 可关闭的帧间隔/分阶段 CPU 采样，地块创建释放计数；暂停时仍完成待处理绘制 | 默认关闭，URL 加 `?profile=1` 开启；不改变模拟时间推进规则 |

小地图暖缓存时，同一视图新增采样为 0；span=128 水平平移 1 单位只新增 130 个像素采样（测试覆盖），避免每次从头采样全部 16384 点。该数字是工作量验证，不等于实际 FPS 提升百分比。

## 实际页面验证及限制

使用运行中的 `http://localhost:5173/?profile=1`，桌面内置浏览器，1279×833 CSS 像素、DPR 1.75。实际存档约第 194–195 天，9 位 NPC 均已死亡；没有重置存档、复活 NPC 或重启世界服务。因此本次不能代表九位活跃 NPC 的完整动画负载。

确认上帝视角、领主视角能显示；原生 D 键按住后领主坐标由 (45.470,51.625) 变为 (46.187,51.270)。这是输入链路可用证据，不是低延迟或持续移动平滑度的定量证明。

| 采样 | 结果 |
| --- | --- |
| 上帝视角一段滚动采样 | 约 32 FPS；600 帧 P50 33.3ms、P95 58.3ms、P99 75ms、>50ms 共 59 帧 |
| 同段阶段均值 | 地形 0.134ms、小地图 0.209ms；普通渲染提交 16.39ms、更新阴影的渲染提交 20.79ms |
| 同段场景计数 | 588 calls、约 315 万提交三角面；地块 81、待建 0、创建 81、释放 0 |
| 领主视角保存采样 | 约 34 FPS；600 帧 P50 25.2ms、P95 42ms、P99 50.4ms、>50ms 共 12 帧 |

浏览器证据：`performance-phase1-browser.json` 和 `screenshots/performance-phase1-lord.png`。截图已人工查看：领主、地面、房屋、小地图正常可见。

这些是开发模式下的不同视角/天气滚动样本，采样期间有测试进程占用，且没有相同世界路径的旧版 A/B 基线；不能将差值归因于本批优化，也不能宣称达到 60 FPS。渲染提交是 CPU 调用耗时，包含驱动等待等因素，不是 GPU 计时。阶段各自保存最近 600 次调用，阴影与普通帧的样本时间范围不同，不应简单相加。

页面频道可见“存档连接异常：signal timed out。正在重连。”，这是另外的运行时同步问题，本批没有声称修复。

## 诊断方式与下一步

开启 `?profile=1` 后读取场景 canvas 的 `data-performance`：`frames` 与 `cpu` 内单位均为毫秒，包含 count/p50/p95/p99/over50/mean；约每 1.2 秒发布一次，窗口最多 600 次。`terrain` 包含 chunks/pending/created/released。关闭参数后不再采集。

下一阶段优先定位渲染提交和阴影：固定存档、视角、分辨率及天气下，分别测阴影、远处实例/草木、天气表面查询和离屏角色表现；生产构建复测。不要直接把高提交耗时归因于模型文件大小，也不要据此全局降画质。最终流畅度目标仍未达成。
