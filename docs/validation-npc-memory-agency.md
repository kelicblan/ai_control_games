# NPC 持续记忆与社会自主行为验证

日期：2026-10-15。对应设计 `docs/superpowers/specs/2026-10-15-npc-memory-agency-design.md`，实现计划 `docs/superpowers/plans/2026-10-15-npc-memory-agency.md`。

## 已接入的运行链

世界服务初始化每 NPC 的有界记忆工作集，记录真实行动结果、行动切换、身体显著变化、自言自语、玩家交流和 NPC 当面交流。发言与事实分开，未在场角色不自动获得交流。世界推进与相关经历在同一 SQLite 事务提交；失败停止该世界继续暴露未保存状态，重载最后保存的快照。

原始经历持久保存，近期工作集 48 条；旧经历每批 64 条形成带原文 ID 的确定性摘要。长期检索按相关主题选择摘要，再检索证据。台词润色是同一逻辑发言的追加版本，具有新的日志水位，不重复产生交流奖励；旧快照只读其水位以前的版本。恢复后使用新分支，未来分支不可见。仍存在的旧心智事件、社交记忆和线程对话按原发生时间一次性迁入，不重新施加情绪奖励；已裁剪的历史无法还原。重置清除该玩家所有运行记录，保留模型配置、认知选择及 NPC 初始模板。

基础 MLP 继续提供八动作偏好。`utility-v1` 根据性格、诉求、情绪、关系与有界模型偏好产生高层意图概率并使用持久随机状态采样；它不是新训练的神经网络。无实际不满依据时保持基础策略。身体自救和物资返送不会强制解除罢工，低库存不能强征罢工者生产。

招募走实际导航；到达可听范围且地图可直达后才发出邀请，受邀者独立选择加入、拒绝或劝解。同轮去重、邀请冷却和群体数量有上限。集体诉求可听取、拒绝、安排休息/口粮或减轻劳动；承诺需实际行动与恢复验证，到期未兑现才生成失约。再次听取诉求不取消已建立的恢复承诺。

## 模型设置与真实验证

默认启用社会自主行为与认知。根据用户最终要求，认知自动绑定当前实际生效的对话模型，不再提供单独的认知模型选择器。未选择优先模型、优先模型加载中或已回退时，认知使用内置 MiniMind3；本地 Qwen 就绪后自动切换到对应本地认知后端。刷新继续跟随，重置保留绑定。旧版 opt-in 存档一次性迁为默认开启与自动绑定，保留玩家主动关闭社会行为的选择。认知失败、超时或过期时继续心智策略，不阻塞模拟；页面关闭后保持最后同步的后端选择。

当前登记的 Qwen3.5 0.8B、Qwen3.5 2B、Qwen3 4B 均已真实本地生成并通过结构、证据与世界接纳校验，全程不读取远程凭据。本地原生认知使用独立 llama.cpp 推理槽和本地清单，不卸载对话模型；JSON schema 约束结构，宿主仍复核证据与偏好。实际修正了 Qwen 思考前缀与 chat JSON grammar 冲突，以及路由器异步卸载后过早加载下一模型的问题。本地模型发现立即发布，不等待远程测试配置返回；本地失败不自动调用远程模型。

首次真实验证耗时约 25.5 秒、19.2 秒、52.1 秒；4B 复测冷启动约 59.8 秒、同进程热推理约 30.2 秒。原生请求预算为 60 秒，服务端一次只发出一个原生认知票据，不让排队消耗票据有效期；按玩家与 NPC 轮流调度。原生票据有效期为 60×发出时模拟速度（1/2/4）的模拟秒，默认与远程仍为 45 秒；状态指纹、世界世代、分支、设置版本与证据校验继续生效。处境改变仍会拒绝较慢结果，以上合成验证不能证明复杂处境理解准确率或连续实时世界中每个结果都会被接纳。离线补算期间保留经历并暂停模型请求，自动模型绑定配置可以独立同步。

MiniMind3 复用浏览器台词模型相同 SHA-256 的本地 GGUF，由世界服务通过项目内 llama.cpp 独立推理槽运行，无需远程凭据，不影响短台词模型选择。首次使用校验并加载权重，认知请求串行执行，沿用调度取消、超时、存档世代与证据校验。权重或原生运行库缺失时回退心智策略。

真实测试发现 64M 模型直接自由输出 JSON 虽可通过语法约束，但摘要存在无意义内容。因此 MiniMind3 采用候选解释选择：宿主提供有当前身体事实和记忆证据的八种状态解释与意图，MiniMind3 根据中文性格、经历来源、诉求、环境与此前摘要选择一个；宿主展开为统一认知协议。候选摘要、情绪微调和表达使用模板，属于受限认知，不宣称与 Qwen 等原生模型自由理解能力相同。模型选择仅增加有界意图偏好，实际执行仍须满足世界合法条件。

本地真实权重推理实测约 1.2 秒，返回的合作解释与证据被世界接纳；此记录证明推理与接纳链路，不证明复杂情境理解准确率。新增测试验证无远程配置的入口、本地路由、单槽并发、取消、模型选择影响偏好和无效输出拒绝；本次相关 21 个文件 46 项测试及生产构建通过，未重新运行整个项目测试集。

代码审查另修正了本地提示词中自述/先前模型理解的来源标记，避免把它们写成本人亲历事实；修正后相关 6 个文件 19 项测试通过。早期独立选择入口在 QA 中完成保存/刷新验证，现已依用户要求替换为自动绑定。此前强制停止/后台启动命令曾被自动审批拦截；本次改用经过项目身份校验的游戏自身管理接口正常关闭，以及受管理进程直接启动，已成功加载新版本。18081 健康检查返回 cognitionBinding=dialogue、本地与测试后端列表、errors=0；游戏入口仍为 5173。已额外完成 SQLite 一致备份与配对密钥备份，完整性检查通过。

自动绑定浏览器验证（独立 QA，1440×1000）通过：默认开启/MiniMind3，无独立选择器，切换对话模型到 Qwen3.5 0.8B 后认知同步切换，刷新继续跟随，取消优先模型后认知回到 MiniMind3。多标签页中只有可见且获得焦点的页面可更新共享绑定，防止不同模型的后台页面持续改绑并取消认知。状态迁移、重置、重开、补算期间同步与单槽/跨玩家轮转均有测试；纯模拟仍可使用无 agency 的旧创建方式，服务创建的新世界默认包含认知设置。

额外尝试让 QA 世界连续运行并通过 HTTP 观察自动认知时，服务持续处于离线补算状态，暂停请求返回“正在补算离线世界，请稍后再操作”，未获得该场景的自动调度验收结果。直接真实模型推理、世界认知接纳、调度单元测试与界面保存分别有证据，不能将其合并宣称连续运行场景已经通过。QA 服务已通过自身控制接口正常关闭。

认知输入包含身体属性、性格、工作负担、已知世界信息、有效诉求、相关记忆和已知伙伴。输出校验固定结构、证据 ID、合法人物与偏好上下界；单个 JSON Markdown 围栏可剥离，但周围说明文字和非法字段仍拒绝。天气、寨门、身体属性区间及诉求变化会使不再适用的结果失效。只依据本次真正引用的新外部证据调整情绪，不因夹带新无关经历或重复润色而重复奖励。

使用当前已保存的 `glm-5.3-flash` 配置进行了真实生成，未显示或新增凭据。独立测试世界接纳真实模型输出，证据校验通过，继续产生 9 个实际 NPC 行动决策。该验证使用明确的合成处境（精力 25、饥饿 60、休息被拒），没有替玩家开启认知或改写玩家剧情。当前模型返回的总结正确区分身体状态、性格倾向、已发生拒绝和未知领主动机。

## 验证结果与边界

- 定向回复因果链修正：实际存档中的“小米 @阿野 你的想法很好”对应一次交涉邀请；经历日志确认阿野已提出“一起谈”，小米实际选择劝解/暂不加入，而不是认可加入。原链路允许未发布的 NPC 模板进入模型历史，也允许依赖回复在前句生成失败后继续生成。现改为只把已保存的 NPC 最终台词作为已说历史；定向回复等待前置最终台词发布，保存 replyToId，服务端拒绝不存在、不同线程或对象不符的前置记录。集体邀请/加入/拒绝记录独立 act，模型不能抹掉实际决定；没有发言依据时拒绝“你的想法很好/你说得对”等虚构回应。主模型与兜底都接收真实对象、实际前句和本句决定。相关 14 文件 228 项通过；补充提示词预算回归后 8 文件 60 项通过，构建通过。旧错误记录保留为历史，不补造阿野的模型台词。此修正不证明任意模型输出都具备完整语义正确性。

- 口语与情绪表达修正：主模型和 MiniMind3 兜底都接收性格化口语要求，允许不满时抱怨、顶嘴、粗话；急躁、油滑与温和克制的表达倾向由当前人格属性提供。拦截用户报告的鸡汤、公文、分析情绪/诗句等助手腔，并排除旧 NPC 鸡汤对话对新生成的示范影响。原有事实、行动与拒绝立场校验保留；明确的顶撞表达不再因未出现旧拒绝关键词而被一概拒绝。相关 8 文件 91 项测试和构建通过。真实本地 Qwen 0.8B/2B 已产生粗口或顶嘴，但也出现说话对象/立场错位；MiniMind3 多次仍产生旁白或分析腔，实际被拒绝。没有把模板替换写成真实生成成功，也没有证明每句输出都能稳定口语化。此次未运行全项目测试。

- 本地原生认知与自动绑定最终专项：41 个文件、161 项通过，覆盖 NPC 认知/记忆、本地路由、模型管理、权威世界 HTTP/客户端、存档、重置、补算及导航相关回归。生产构建与 NPC 包边界检查通过。浏览器在加入焦点所有权后再次验证默认开启、无选择器、Qwen 同步、刷新同步与 MiniMind3 兜底，全部通过；独立 QA 服务正常关闭，当前 5173/18081 游戏服务保留运行。未将专项结果宣称为全项目测试通过。

- 新功能专项：19 个测试文件，34 项通过；覆盖旧记录与原时间迁移、记录去重、回退分支、润色版本、未来版本保留、长期检索、认知协议、并发和取消、情绪证据、实际自救、邀请、个人停工后继续招募、兑现、开关与重放。

- 桌面 Playwright：1 条完整交互场景通过（1440×1000，独立 QA 数据库/端口）。验证认知设置、NPC 资料、历史分页、发言来源和集体休息承诺。内置浏览器因本机桥不受信任无法连接，已使用项目 Playwright 作为替代。

世界服务已加载 NPC 自主协议 v1、经历数据库 schema v2，健康检查无错误。运行时可关闭认知或社会自主功能；记录和诉求保留。退回旧程序必须先停止当前世界服务，再恢复对应的迁移前数据库及配对密钥，不能让旧程序直接运行新格式存档。回滚前应另备份当前进度，避免覆盖迁移后新经历。
