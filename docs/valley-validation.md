# 山谷村寨地图交付记录 · 2026-10-14

## 实际改动

- 300米直径木寨，一座完整领主府、五座分散的属民居所、南侧寨门及瞭望塔；入口走廊留空，主路连通广场与领主府，五条支路连接民居。
- 领主府和民居恢复完整生成网格，统一朝向主路，保留源GLB拓扑。去除了曾经人为裁掉三角形的门洞处理。
- 撤掉放大后像独立石堆的山体资产。现有山脉是连续的三维地形网格，包含相连山脊、山坡、鞍部和河谷，使用现有Tripo岩石资产纹理表现裸岩。不是重新生成的Tripo山脉模型。
- 外围树林按空间噪声形成疏密林团和林缘，位置跨网格随机偏移，避免等间距树阵；寨内树木使用明确设计点位。
- 寨内与近郊加入弯曲草叶组成的三维草甸，叠加Tripo草丛、灌木，避让泥路、院落、台阶与入口。地面底色及细纹理同步改为自然绿色。
- 河流、桥、岸坡、树林和房屋的渲染与通行使用同一地理定义。测试覆盖实际走出寨门、过桥、返回，以及所有住宅床位可达。
- 老存档按布局版本修复新障碍中的位置和路线，重新分配自家休息点，保留身体、物资、历史与远方坐标。负坐标的听觉位置不再裁回0到100。
- 重复小型景物使用派生LOD和实例批次；原始付费GLB保留不变。平移视窗时已经加载的树林块也会更新近远细节。

## 运行与验证

开发预览：<http://127.0.0.1:5180/scripts/valley-preview.html>，使用真实游戏场景、独立固定昼间状态，不覆盖用户游戏存档。支持据点全景、领主府、寨门与主路、山脉与林地四个视角。

实际浏览器截图见 `screenshots/valley-overview.png`、`valley-manor.png`、`valley-gate.png`、`valley-landscape.png`。截图是运行画面，不是生成概念图。浏览器检查未发现渲染错误；稳定加载后本机观察约40到60 FPS，性能取决于视角、设备和同时运行的其他页面。

- `npm run build`：通过，仍有既有的大包体积提示；后续最后一轮TypeScript检查通过。
- 最终地图相关检查：9个测试文件、48项全部通过，见 `valley-scoped-test.log`。
- 存档专项检查：125项通过；连同寨门往返检查共132项通过。
- 全量检查：522项中514项通过、8项失败，见 `valley-full-test.log`。随后修复音频坐标与旧场景测试的地理来源，并通过上述48项检查。
- 对长时模拟、召回和服务单独复查：20项中18项通过；仍有生存模拟5秒超时、独立服务SQLite快照数量断言失败，见 `valley-runtime-recheck.log`。未宣称完整测试集全部通过。

当前画面仍与参考插画的岩壁造型、林冠层次、建筑装饰和光照精细度存在差距。连续山体和草甸已是实际三维几何，但不能把它描述为原图像素级复刻，也不能将被撤下的石堆资产称为已交付的Tripo山脉。
