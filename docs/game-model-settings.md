# 游戏级对话模型设置

从开局页的“游戏设置 · 对话模型”、游戏顶部的“设置”或营地面板进入。MiniMind3 是固定内置兜底，不在优先模型列表内。优先模型可选择本机 Qwen 或配置远程接口，也可选择“不使用优先模型”。选择立即生效并跨刷新、新局保存；关闭窗口继续加载。

运行：`npm run dev`，或者先 `npm run build` 再 `npm run preview`。两种模式都有同源 `/model-api` 桥接；不必手动运行gamesoul/start.ps1。原生运行程序和模型需要已放入gamesoul/目录，本项目内已准备。

## 三种运行后端

- MiniMind3：页面启动即后台预加载，不等待场景或开局。浏览器 Worker/WASM；SHA 校验后保存独立 CacheStorage，不可用时使用 IndexedDB。运行库使用独立内存存储接口，不要求 OPFS。刷新会重建 Worker 并重新加载到内存；缓存可用时无需重复下载 GGUF。切换优先模型不卸载它，重置游戏不删除模型缓存。浏览器主动清理站点数据或禁用全部存储时仍可能重新下载。
- 原生模型：Node宿主管理项目内llama.cpp router及模型子进程，默认只允许一个原生模型。刷新页面后，如果所选模型、文件元数据和配置未变化且仍驻留，直接复用原operation，不重新校验或加载权重；切换模型、服务退出或文件/配置变化后才重新准备。

- 远程模型：游戏设置中添加名称、HTTP(S) Base URL、模型 ID 和可选 API Key，支持 OpenAI 兼容 `/chat/completions`；地址可填写到 `/v1` 或完整接口路径。配置按当前玩家保存到 `data/world.sqlite` 的 `remote_models` 表，API Key 使用 AES-256-GCM 加密；列表仅返回是否已设置密钥，调用时由服务端读取。刷新和服务重启后继续有效，编辑时密钥留空保留；更换接口域名必须重新填写。支持测试连接、编辑、删除；测试和选择会发送简短请求。台词经同源 `/game-api/remote-models/generate` 转发，不需要浏览器跨域权限。

当前玩家沿用存档的 HttpOnly cookie 身份，不是登录账号；清除 cookie 或换浏览器会成为另一位玩家。启动时先建立共享会话，防止存档和模型并发请求创建两个身份。重置世界不会删除远程模型配置。加密文件为 `data/world.sqlite.remote-key`（自定义数据库时跟随数据库路径），备份必须同时保存数据库和该文件；不能丢失或提交密钥文件。

营地 MiniMind3 兜底采用候选选择：宿主先按当前立场、事实和最近台词筛出短句，真实 WASM 模型在语法约束下输出候选编号，映射为对应短句后再次经过正常提交校验。它是模型选择的台词，不是自由生成的新句子，也不是把代码兜底直接改成模型标签。优先远程模型仍使用完整营地提示词自由生成。

UI 分别显示内置兜底与优先模型真实进度，并标明实际使用模型。原生百分比来自 llama.cpp `/models/sse`，不伪造进度。无优先模型、优先模型加载中或出错时使用 MiniMind3；生成故障同次请求尝试 MiniMind3。MiniMind3 也不可用时保留即时回应。优先模型失败保留选择，30 秒冷却后重试，连续准备失败最多自动重试两次；成功恢复后重新优先使用。用户取消、旧选择的请求不会触发故障回退。

## 增加其他模型

MiniMind3 与优先模型分别管理重试预算；MiniMind3 加载失败后等待 1 秒、2 秒各自动重试一次，仍失败则提供手动重试。普通状态轮询不会重置预算。“重试 MiniMind3”只重试内置模型；“重试加载”或重新选择重置优先模型预算。

编辑gamesoul/models.json，登记唯一id、名称、相对于项目根目录的GGUF路径、SHA-256、threads和context。路径必须留在项目内，SHA-256必须为有效64位十六进制。可用`Get-FileHash -Algorithm SHA256`取得校验值。点击“刷新本地模型列表”后进入列表；选择时宿主会按需刷新原生配置。不要在列表中配置LoRA合并模型或视觉投影文件，除非已经验证其兼容当前原生引擎和文本提示词。

原生模型请求不接受任意可执行文件、远程 URL 或 shell 参数；模型 ID 来自清单。原生缓存、进程日志和运行资源保存在项目 gamesoul/ 下，权重及二进制不提交 Git。远程代理仅允许公网 HTTP(S) 目的地，校验全部 DNS 结果并固定连接地址，不跟随重定向；限制输入、响应大小及超时，错误不包含密钥或提供商原始响应。

## Web与桌面边界

静态 dist 网站仍可使用 MiniMind3；本机模型和远程转发均需要运行游戏服务。纯网页没有权限启动用户电脑上的 exe；选择原生模型必须连接本地宿主。ModelManager 依赖 prepare/generate/unload 契约，内置模型生命周期独立于优先模型。本次未打包 Steam exe。

对话生成保留世界快照、人格、知情记忆、台词校验和旧请求失效规则。用户切换清空旧模型调度缓存；实际来源为 `minimind3`、`native:<model-id>` 或 `remote:<model-id>`，存档支持这些来源。原生请求上限 5 秒，远程生成上限 30 秒，连接测试上限 20 秒；营地完整请求期限 65 秒，覆盖远程失败后 MiniMind3 原有 30 秒推理窗口。GLM-5.3 使用 low 推理档位。始终异步，不阻塞模拟。模型不直接修改物资、任务或承诺。

台词过期、切换人物或模型时，旧请求按取消处理。MiniMind Worker 五秒未确认取消则回收并从缓存重建，不记为模型故障、不消耗故障重试预算。真正的备用 MiniMind 错误在优先模型正常时以备用模型警告显示，不代表当前 GLM 失败。

普通台词在途请求忽略同一心智意图的计时续期和其他人物的社交日志变化，并允许在气泡到期后的 12 个模拟秒内提交；前端和存档服务共同校验。同一句即时回应再次出现时仍可重新请求模型，但不会取消语义相同的有效在途请求。人物有心智表达计划时，以该计划的语气判断立场，不用行走、天气等更新的表情标记替代它。

远程自由生成和社交回复继续严格校验完整上下文。普通 MiniMind3 候选短句允许在走动、天气变化后重新校验：必须仍属于宿主按当前状态筛出的候选句，命令、交互、伤害、需要、心智意图及表达立场也必须一致。不能借此接受任意旧生成文本。社交对话仍按原有效期处理，加速模拟会缩短普通台词窗口的实际时间。
