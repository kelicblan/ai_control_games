# 寨外劳作与动物生态验证（2026-10-14）

## 实现范围

- 首圈 84 处真实资源：24 处采伐树木、16 处浆果、16 处野菜、16 处块根、12 处菌菇。按种子确定位置，避开寨墙、道路、河水、陡坡和已有树干。
- 初始 22 只兔子、15 只野鸡、5 只野猪、1 只远处老虎；觅食/停留/逃跑/冲撞/死亡与延迟补充。
- 资源预留来自仍存活、正在执行的任务，不依赖另一个易泄漏的锁表。到点消耗资源，携物经桥、寨门返回库存；肉类增加回寨处理时间。
- 普通食物任务只采植物。玩家可独立发出狩猎指令，保留八种策略动作；勇敢且健康的猎人可面对本轮指定野猪，普通采集者避让；老虎触发撤离。
- 原普通探索随机奖励改为真实植物采收。寨内庭院树保留，移除旧采食模型和采木/浆果任务标记的误导绑定。
- 采木朝向真实树干，食物显示篮子，狩猎有投掷姿态，任务栏显示来源与往返阶段；地图只标记已发现资源。
- 所有生态、库存和任务状态由权威模拟保存；镜头和模型对白不产生采集/伤害/掉落结果。

## 验证证据

- `tests/wilderness.test.ts`：真实出寨/过桥/返程、关门阻挡出发和携物返程、资源排他与耗减、不能在寨内凭空采集、存档恢复不重复收获、移动猎物完整狩猎、野猪风险、老虎撤离、禁止隔障碍狩猎、生态时钟边界、树木接触历史。
- 三昼夜规则策略回归：实际推进 1800 秒，采食累计至少 50 份，至少三名队员存活，最终状态可保存。修复前仅获得 12 份食物并全员死亡；根因是旧随机兽声长期累积全局危险。现改为实际动物威胁与昼夜底值，声音不凭空致伤。
- 独立审查验证 1、2、3、17、20261012 五个种子的采木/采食共十趟：每趟实际入库四份。
- `tests/wilderness-runtime.test.ts`：狩猎指令经过世界服务协议校验，并从真实 SQLite 恢复目标与生态状态。
- 全套回归：`npm test -- --maxWorkers=2 --testTimeout=60000`，77 个文件、609 项测试全部通过，退出码 0；日志 `wilderness-release-tests.log`。旧存档测试补齐生态时间；真正旧档缺少生态时，按已保存游戏时间初始化，保留人物身体、已携物资和历史观察，重新规划旧寨内空手劳作。
- `npm run build`：退出码 0，见 `wilderness-build-results.log`。保留现有打包体积提示。
