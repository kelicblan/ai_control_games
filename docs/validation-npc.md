# 可复用 NPC 心智与营地人物升级：验收记录

日期：2026-10-13。基线提交：`d91405f34131875763499c2634e224168c31be37`。

## 交付结构

本次先编写 [设计](superpowers/specs/2026-10-13-reusable-npc-design.md) 和 [实施计划](superpowers/plans/2026-10-13-reusable-npc.md)，再实施目录迁移、通用核心、营地适配和语言后端拆分。

- `packages/npc-core`：九项人格参数、情绪、持续诉求、事件和记忆、行为裁决、有效投入、独立同伴响应。
- `packages/npc-dialogue`：注入宿主与后端的异步队列、缓存、取消、重试、过期结果隔离和提示词编排。
- `src/games/camp`：实际营地人物、资源、地形、天气、指令理解、事实校验、执行和存档。
- `src/integrations/minimind`：浏览器模型加载、校验、WASM worker 和缓存；不导入营地模拟。
- `examples/restaurant`：相同核心驱动备餐、上菜、休息，包含世界执行和确定性存档回放；不导入营地代码。

两个包导出 TypeScript 源码，无额外运行时依赖。公开契约和关键状态转换有中文注释，各自 README 说明量纲、所有权、调用顺序和复用条件。CI 增加 `npm run check:npc`，禁止反向导入宿主、DOM 或第三方 SDK。

## 已实现的行为约束

老周是自利、低诚实的老油条，存在有实际进度后果的磨洋工和掩饰。林枫懒惰、偏激、易冲动，能顶撞、拒工、自主休息和拉拢共同不满的伙伴。人格参数影响倾向，身体需要、真实收益、信任和亲历事件改变选择。

同一轮未满足诉求保留被拒绝次数，重新安排、手动移动和存档恢复不能将其清零。人物实际休息或吃饭后才完成相关承诺。已形成的停工有最短持续时间；语言模型仅表达立场，不负责修改动作、完成记录或库存。

集体反抗的范围是公开串联与联合停工。只有在范围内或确有共同交流而知道抗议的同伴才参与评估；各自的不满和关系决定是否加入。本版没有新增战斗、夺权或领地系统。

身体紧急需要和已携物资返送优先。最后 30 秒明确召回或基础策略选择返营时，可以先到安全集合区继续表达不满，不获得额外服从奖励。休息点的位置作了小幅修正，避免长期休息者堵住其他人的帐篷通路。

## 回归和兼容性

原 MLP 的 41 维输入、8 种动作、5 种情绪及权重保持兼容。心智覆盖候选时，日志标记 `rules` 并记录原因，保留原模型分数，不伪称模型输出。评估脚本的来源指纹已包含核心和营地适配文件。

旧三人、旧五人和无心智字段的存档迁移保留身体、库存、进度和历史；当前显示名更新为林枫，稳定 ID `linlan` 保留。新心智数据严格校验，未来版本不会作为坏档清除。和解阶段字段可选，兼容已有 v1 心智存档。

独立审查发现并修复：忽略取消的后端堵塞逻辑队列、首句校验却提交多句原文、永久离场角色未清理对话状态、暂停重复道歉刷信任、自主同伴治疗误奖玩家信任，以及低勤奋角色缺少可达的条件合作路径。各项均加入针对性回归。

实际引擎评估使用 seed 7、三种场景、normal/hard、MLP/teacher 共 12 个无人干预组合，另加两次困难风暴救援。救援使该样本存活时间延长，但没有挽回熄火失败；不能据这批描述性样本宣称模型优于规则或保证玩家获胜。记录的推理耗时来自不渲染画面的 Node.js 环境，不能当作手机性能。

浏览器验证使用 Chromium Headless Shell 141，覆盖桌面、手机竖屏与横屏。当前 Playwright 默认浏览器下载被中断，因此使用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向已成功安装的兼容浏览器。真实 MiniMind 使用固定 SHA-256 校验的 GGUF，通过同源 WASM 运行。

真实模型诊断曾复现新增上下文导致 8 秒超时。修复采用去重和 560 字符总预算，保留完整最新玩家输入、当前立场和未解决诉求；没有延长截止时间或放宽事实校验。诊断中真实首句在约 6.2 秒显示；最终浏览器用例也已通过真实生成、同源请求、本地缓存、断网重载和无需重新请求 GGUF 的完整链路。这是该测试环境的结果，不是所有设备的延迟或台词自然度保证。

全套检查首次为 21 通过、3 个旧界面断言失败：基线紧凑 HUD 已经移动头像、精简可见状态文字，但这些断言仍指向旧位置。回归改为读取当前人物栏头像与 `aria-description`，保留暂停后命令不丢失、头像不变形、离线真实模型继续决策等原有验收目的。异步音频设备解锁会短暂禁用按钮并移走焦点，键盘测试在每次操作前显式聚焦被测按钮，同时继续检查空格不会误切游戏暂停。三个用例已补跑通过，产品布局未作额外修改。

## 实用边界

- 这是一套可复用的 TypeScript 规则与效用决策核心，不是自动理解任意世界的通用智能。新游戏仍需提供合法候选、世界观察、收益和执行器。
- 中文输入目前识别明确的休息许可、拒绝、催促、道歉和核查。疑问、引述、条件句和歧义输入不擅自执行；复杂分食和承诺仍有结构化按钮。
- 语言校验是保守的规则检查，不能证明所有自然语言都真实；世界执行权始终不交给生成文本。
- 基础游戏无需 MiniMind；模型缺失、损坏、超时或回答不合格时保留与人格立场一致的即时回应。
- 包目前为源码交付，没有声称已经发布 npm 包或完成 Unity、Unreal、小游戏原生平台适配。
