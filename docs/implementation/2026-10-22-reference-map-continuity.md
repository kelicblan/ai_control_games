# 设计图地形与连续缩放候选版

## 实现

- 原设计保存在 `native/ArtSource/reference-region/approved-design.png`。左侧区域图的边界、山体范围、森林范围、主河流与支流、湖面、道路、湿地和地标，统一在 `src/games/camp/world/pixel/reference-layout.mjs` 描线。Unity、碰撞、分块、总览和区域远景都读取同一权威地图。
- 村寨移动到设计图的对应区域；保留现有五座民居、议事厅、工坊、储物间、火塘、水井、寨墙和寨门。河道与古道的交点生成有碰撞、有桥板实体的桥梁。
- 删除“进入远景即关闭详细分块”的逻辑。仍保留最多 64 个详细块，其余内容由同源远景合成图承接；地表透明度过渡不关闭建筑、树木等实体。
- 地形采样与绘制分辨率分离：服务端总览 1024、区域 512；Unity 在 2048 纹理中使用近景相同素材重新绘制山体、树木、建筑和桥梁，并沿用相同地表配色。山体采用较大的合并山群，避免远景被密集微型山块铺满。全域中的村寨有保留内部布局的缩略表现。
- 鹰眼渲染时临时隔离主相机的远景合并图，并使用本地详细地表；64 块预算中保留最多 16 个村寨块，避免主相机远离后鹰眼变空或使用放大的合并图标。
- 最远缩放可以容纳完整区域。文字仍单独按远景规则显示。近景 NPC、资源和动物继续使用正式世界状态；远景快照补充当前活跃动物，避免仅因相机观察范围变窄而删除这些个体。
- 正式旧档升级前备份 SQLite。迁移版本 `referenceLayoutVersion:1` 仅调整实时地理位置并取消迁移前仍在执行的任务、清空路线；世界身份、人物身体与库存、资源数量、历史事件和模型配置不重置。固定森林食物点使用新地图规定的对应站位，保留采集账本；受阻的已存区域动物站位作安全投影。

## 验证

- 地图 Node 测试 71 项通过；新增设计锚点、河道控制点、各缩放档村寨内容保留检查。
- Unity EditMode 19 项通过，包括真实建筑/树木素材远景合成、树根固定与随风摆动、坐标协议与全域覆盖、斜向桥梁、村寨缩略图不会被相邻山群盖住。
- TypeScript 村寨检查通过；动物运行、迁移和重置回归 6 项通过。
- 正式 SQLite 副本迁移：世界 ID、10 名角色、身体、库存、资源剩余量及既有事件保留；生成备份；再次启动不重复迁移。
- 使用可见原生窗口实拍近景、中景及全域。第一轮发现分块接缝与远景像素化，已调整配色和合成分辨率。随后发现高分辨率权威采样在并发负载下超时，已分离采样/绘制、增加总览重试，且截图探针现在必须等总览就绪才开始。

## 验收边界

这是一版按参考图描线重建的可运行候选，不宣称逐像素或 100% 原画还原。原图中的手绘地表细节、岩壁形状、所有小支路和逐棵植被位置仍有差异；远景采用合并山群、森林和村寨缩略表现，不同时实例化全域 62500 个详细地块。动物生态仍保留既有区域化推进与观察预算，不宣称全域所有动物都同时作近景模拟。

首轮失败画面与最后通过画面分目录保存于 `native/Artifacts/reference-map/`，不以编译或某次截图文件存在代替视觉检查。
