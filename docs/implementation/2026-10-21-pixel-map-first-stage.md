# 一寨之主：二维像素地图第一阶段

## 状态与基线

用户于本轮确认32km×32km区域、十人村寨及西北金矿设计后启动实现。基线为 `66da335c9dd97ce0ad0ae2bab0e2b0c6a9e04de6`，功能分支 `feat/pixel-world-32km`。本次全部为新增文件；没有替换正式Camp场景、正式游戏启动指针、现有TypeScript世界服务、模型权重或用户存档。

这是**Unity独立地图验收版本的源码**，不是已经完成正式玩法迁移的发行包。无需访问远程大模型即可测试地图基础功能。画面采用原创程序化像素首版精灵，不将参考图直接贴作背景；最终美术质量仍需Unity实机与用户验收。

## 已实现内容

地图使用真实米制坐标：x向东、y向南，首批范围0—32,000米；总面积1024平方公里。村寨180×160米，宽度仅占世界0.5625%。世界总览和鹰眼均由地形采样生成，标记只是导航符号，不代表房屋实际占地。

村寨中心(13824,17408)，南寨门中心(13824,17488)，12米门洞，旁设瞭望塔。寨内有1座寨主住所兼议事厅、5间双人村民屋、1间工坊、1间储物间，公共水井和避开主路的火塘；规划床位1+10，适合寨主加9名村民。当前建筑为外观和碰撞实体，没有宣称房屋室内或住宿系统已迁移。

西北金矿位于(3600,3600)，设置500单位有限金矿石。近郊有木、石、纤维和莓果，丘陵石场有集中石料；南部平原、东北深林、山口、河谷、湿地及古道遗迹按地形分布。河流使用连续曲线，已布置两座实体木桥。边缘道路与河流延续，首批边界暂时限制行走，不伪称当前已实现无限世界。

地图按128米分块，单块64×64地表格，每格2米。宿主缓存最多96块；Unity视口最多64块、同时请求2块，离开视口释放地表纹理与实体。资源ID由坐标和生成版本确定，不随读取顺序变化。碰撞、桥梁、资源位置、鹰眼和总览均以同一权威几何模块为准。

地图宿主按固定步处理输入，移动速度4.5米/秒；输入断流300毫秒后停止，连续扫掠避免单次大输入穿墙。E键在门旁切换寨门，在资源旁采集；资源会减少、耗尽，并写入独立SQLite。操作ID防止重复请求重复加库存。相机勘察不会传送玩家，也不会解锁玩家尚未到达的探索块。

## 在Windows/Unity中打开

先在正确工程目录同步本功能分支，保留本机未提交工作，不执行强制重置或清理。工程目录仍为用户指定的 `D:\workspace_zsfz\ai_control_games\ai_control_games_unity`。

1. 双击仓库根目录 `打开2D像素地图.cmd`。入口复用已有Unity启动器与BuildReport端口保护。
2. 若Unity提示保存当前场景，先保存；入口随后打开独立、未保存的二维地图验收场景。也可直接使用菜单 `CampMind → 二维像素地图 → 打开独立地图验收场景`。
3. 按Play。编辑器启动自己拥有的Node地图宿主，读取独立连接文件；停止Play后只关闭该宿主。

要求现有项目指定的Unity `6000.3.26f1`、PowerShell7.2+及Node24+。Node不在Unity可见PATH中时，设置环境变量 `CAMP_PIXEL_NODE` 为node.exe绝对路径后重开编辑器。新地图宿主没有额外npm依赖；原Unity项目依赖仍需正常导入。

操作：WASD行走；E采集/开关寨门；滚轮缩放；中键拖动或方向键勘察；Shift加速勘察；Home跟随人物；M打开全区域地图。点击区域图只定位相机，随后Home回到人物。全图是规划视图，刻意展示全区域；探索比例仅由人物实际位置更新，未实施战争迷雾遮罩。

## 安全与存档

编辑器独立存档：`native/LocalData/pixel-map-preview/editor-world.sqlite`。命令行默认使用同目录`world.sqlite`。这些文件按原.gitignore规则不提交。

宿主只绑定127.0.0.1，每次运行使用随机令牌，客户端只从本机连接文件读取；不写日志或PlayerPrefs。Host/Origin与令牌校验、4096字节请求限制、参数边界及请求超时均已实现。SQLite应用标识与地图生成版本不兼容时明确拒绝，不重置原档。同一数据库禁止重复启动宿主。编辑器按PID及启动时间追踪所属进程，并设置父进程存活检查；不会按进程名批量结束Node或Unity，不改Windows网络及防火墙。

## 文件职责

`packages/pixel-world-core/src/spatial.mjs`仅提供通用曲线和空间索引；`src/games/camp/world/pixel/world.mjs`存放本游戏区域、建筑和资源规则。`scripts/pixel-world/`负责独立权威宿主与SQLite；`Assets/CampMind/PixelWorld/`负责Unity像素视图和协议。通用几何不依赖村寨、界面或语言模型。
