# 六物种生态与专项模型实施计划

依据用户已批准的animal-mlp-v1-design.md连续实施，不更换HUD、不修改地图。

1. 测试先行：六物种生成、有限食物水源、需求增长、移动碰撞、捕食/逃跑、攻击冷却、尸体与搬运、暂停与重载。
2. 新增src/games/camp/animals独立规则与观察/候选契约。SQLite独立表与村寨事务一起提交，同一100ms逻辑时钟；旧档首次显式初始化，不运行冻结旧世界的动物。
3. 六物种共享网络主干，life/combat输出头；真实规则教师轨迹，按世界种子划分训练/验证/测试，NumPy训练、TS推理、哈希与推理一致性校验。记录失败、动作覆盖及闭环行为。
4. scripts/world动物宿主适配：地图可达森林资源点生成；村寨快照公开动物与模型状态；真实猎捕移动/攻击/反击/尸体搬运，与原人类执行互斥。复用现有伤害/属性计算，不改人类执行器；人类v4来源哈希与回归检查必须通过。
5. Unity独立动物显示器使用六个已验证Prefab，按真实快照位置、动画、死亡显示；保留原猎捕入口并明确目标。禁止仅用静态装饰充当动物。
6. 原生构建、正式旧档副本生成/动画/猎捕/保存重载验收，推广同一构建到正式入口并打开验证。模型与生态指标、性能和未解决问题分别报告。
