# P0 社会化范围与共同责任

本阶段将 SD01—SD06 和能力依赖写入独立配置，全部保持 proposed。没有生成初始记忆、没有改动当前人物、没有自动启用外部推理。

后续共同链路是：真实事件 → 本人可知信息 → 个人目标与关系 → MLP 候选或 LLM 提议 → 各方独立同意 → 世界服务命令 → 实际执行与结算 → 证据核验 → 关系与下轮候选。

| 唯一责任 | 归属 |
|---|---|
| 人物、事件与版本化世界 | T04 |
| 资源预留、执行、物资与伤害结算 | T05 |
| 个人知识、目标、定向关系、事件归属 | S01 |
| 能力协议、条款绑定与独立同意 | S02 |
| 观察顺序、候选和决策追踪 | T06／T07 |
| 装备／休整约定与真实履约 | T11／S03／S04 的同一实现 |
| 风险、值守、救援与战后记忆 | T15／S05 的同一实现 |
| 通用计划、误会与制度 | T17／T18／S06—S08 的同一实现 |

已接受计划不等于强制脚本，拒绝工作不等于放弃求生。事实、发言、信念、评价分别记录；说过“交出装备”不能代替实际交接。模型离线时基础生活与战斗继续，不能冒充已完成复杂协商。

制度仅作用于装备、值守、公共资源和临时小组；本轮不启用税制、婚姻、外交、修炼、货币市场或没有完整动作与后果的越轨能力。

配置文件是范围登记，不是运行时能力证明。P1 冻结接口；P2 接真实制作、交接与最小社会闭环；P3 接救援和战后评价；P4 再扩展通用计划、制度和主动生活。社会配置不写回 Excel 的原值字段。
