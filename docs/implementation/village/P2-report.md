## 真实模型与质量

最终模型 `life-alpha-p2-v3`，文件位于 `public/models/village-life-alpha-v1/`。Life 网络为192→128→64→1，共33,025参数，权重132,100字节。

- 最终数据407组，全部有实际完成的 executionId 和执行结果；训练336组，按种子隔离留出71组。教师为具名生活规则基线，记录 source=fallback；这不是将 P1 测试张量当训练数据。
- NumPy FP32 Adam，300轮、3,300次更新。训练准确率84.8%，留出候选首选准确率78.9%。留出休息9/10、交仓11/15、木2/4、石13/17、绳16/20、制作5/5；小样本尤其木材选择仍弱。
- 独立生产场景种子2001—2004，模型4/4完成采集→搬运→交仓→强化长弓制作；教师对照同规则4/4完成。低能量场景模型108.5秒、教师98.5秒；高能量场景均88.5秒。没有把较慢的模型写成优于教师。
- 最终实际权重的 JavaScript／NumPy 六组输入对照，最大绝对误差约9.54e-6。
- 真实 SQLite 世界中 NPC 使用 source=mlp 自动制作，物品和所有权跨重启恢复；独立 HTTP 服务验证玩家执行、NPC真实权重、隐私投影及重启恢复。

权重 SHA256：`76c6c3c007a3f59d9d7f87b118fddc1cf346fffd89acea1a00ac990481c7d6c0`。

首版模型虽然留出82.7%，实际低产节点生产回放4/4失败并反复休息，已保留失败证据，没有交付为最终模型。第二版修复生产闭环后，又补充休整需求特征及加权排序训练；最终以真实生产结果与分项质量一并报告，未只挑总体准确率。

模型是实验性教师模仿。训练人物原型仅为 H002；不能据此宣称已验证所有原型、多人分工、社会偏好、长期饥饿或战斗。大模型通过协商和 active_plan 影响执行，不将此 Life alpha 的输出分数解释为完整社会推理。关系特征对照诊断保留在 relation-counterfactual.json，只有 trust_player 改变；它不是模型已学会关系推理的证据。

## 真实大模型证据

`native/Artifacts/village/P2/real-social.json` 保留 MiniMind3 的真实 none 结果；`real-social-qwen3.5-0.8b.json` 保留 Qwen 0.8B 的真实休整提议及两名 NPC 独立拒绝。拒绝没有被替换为“接受”，该真实调用没有产生已履约的休整约定。

装备、休整的实际兑现链用显式同意的集成场景验证：工单实际消耗原材料产生弓，实际交接给正确对象后才兑现一次并更新关系；同意休息不立即加体力，推进五秒后才完成并可读档。不能把这些测试里的同意说成真实模型同意。

服务复用当前选择的本地／远程模型与原有配置；只有调用失败才退回 MiniMind3，合法 none／拒绝不会被兜底改成同意。没有调用远程付费模型或导出凭据。

模型不得替玩家同意。玩家参与的提议显示在本人可见的协议投影中，等待本人通过 consent 请求绑定提议版本、条款哈希与操作编号；NPC 私有目标仍不返回。等待期间世界继续。CAMP_SOCIAL_OFFLINE=1 同时停用新模式的大模型社会请求。

## 审查和验证

阶段最终独立审查发现两项重要问题，均已先写失败测试再修复：暂时模型失败／重启遗留事项不能恢复；waiting_conditions 约定不能在条件恢复后重调度。现在保留事项 ID，最多三次重试、指数退避、协商租约；约定根据相关条件指纹重验，不每帧反复创建工单。同一人物的多步串行社会计划明确留给后续能力版本，P2 不把它伪装为同时可执行。

补充实际装备链测试还发现命令事务克隆后约定状态引用失效，已修复并验证 executing→fulfilled。

实际服务的异步补测发现：普通 MLP 任务的接收／完成只改变执行修订，也会把未变的装备条款误判为失效。现以参与者身体、目标、相关证据及物品权利的语义签名重验，并保留显式额外 readSet 校验；普通任务推进不再清掉提议，失能／真实条件变化仍拒绝。失败复现和修复通过日志为 async-social-red.log／async-social-green.log；进一步验证了等待玩家、本人同意、实际交接及兑现的完整持久化链。

最终检查统计、退出码、完整失败项以 `P2-report.json` 和 `native/Artifacts/village/P2/` 日志为准。既有两项 physics 寻路断言与地图／移动基线分开记录。本阶段没有修复它们，也不把后端通过写成 Unity 桌面体验通过。

全量快照为801通过／3失败，并有一次 worker RPC 超时；其中生态长测在独立复跑时通过（约60秒），余下两项为既有寻路断言。全量结束后对玩家同意边界和异步语义重验做了补充核对与修复，最终专项和类型检查覆盖这部分增量，未再重复整套耗时回归。

## 使用与重现

```powershell
npm run village:collect:life
npm run train:v4:life
npm run village:evaluate:life
node --import tsx scripts/village/verify-trained-parity.ts
npm run check
npm run check:village
npm run check:npc
npx vitest run tests/village/ --maxWorkers=1 --minWorkers=1
```

重新采集会改写开发数据及诊断夹具；训练默认写入阶段 retrain 目录，不自动替换当前权重。导出使用 `scripts/mlp_v4/export.py`，校验权重和训练报告且拒绝覆盖已有目标目录。训练依赖 Python／NumPy，游戏推理继续使用 TypeScript，不依赖 PyTorch。

模型加载校验指定执行／观察源码集合的规范化文本哈希；源码变化后拒绝沿用不兼容模型。这不是整个仓库或 Unity 地图的哈希。完整数据在 data/village/life-alpha/dataset.json，留出诊断夹具在 tests/fixtures/village/train-life-alpha.json，归档保留数据哈希与真实训练日志。

## 边界与回滚

新模式入口仍是已有世界服务的 `/game-api/village`，支持配置场景、玩家命令、暂停、取消与招募。场景需提供三类节点位置；useEcologyNodes=true 可通过适配器导入既有木材地点，旧生态不支持的石／绳仍需显式场景配置。当前没有 Unity 新玩法界面或新 EXE 验收。新模式移动采用时间推进的位置插值；复杂地形绕行、多人避障与 Unity 地图结合尚未在本阶段验收，不能声称已有可玩发布版本。

停用实验开关即可回到默认入口，保留新旧存档及模型配置。阶段包为 `native/Artifacts/village/P2/stage.zip`，哈希见 `P2-SHA256SUMS.json`。这是依赖已接受 P1 的增量归档，包含共享文件核验快照，不是覆盖整个工作区的回滚脚本。不得整仓 reset、删除旧世界或覆盖地图任务的文件。当前工作区混有其他在途修改，未混合提交、推送或合并。
