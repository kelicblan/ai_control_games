# 确认稿完整界面还原

用户明确指出前版仅接近布局，要求完全照搬确认图的细节，包含顶部工具条与整个 HUD。

视觉源：本会话 `codex-clipboard-ac67792e-8820-4152-9a68-d520b689617a.png`，1664×941。

按参考图重新测量：左上六项资源同排；中上日期/时段/时刻、圆形暂停和带完整边框的倍速选中态；右上单个当前视角按钮及三个方形工具；两列头像；右侧实景营地鹰眼；左下频道横排页签与空状态；下方四项工具条；金墨管理窗的标题、四项导航、物品插画列表、选中箭头、右侧大插画、用途和制作条件表格、右下操作区及完整宽度的制作队列。

美术资源为参考图生成的透明图集，使用 3×2 固定单元及 Unity UV，不使用手绘线段替代装备插画。动态库存、材料成本、人物姓名、时间及不可用原因继续显示真实状态，不把设计稿中的占位数值作为玩法数据。

不改地图作者的场景、地形与建筑；小鹰眼只拍摄当前已经可见的本地营地，不修改探索记录或世界服务状态。

交付以真实原生截图与确认稿的同视口比较为准，不能用单元测试或编译成功代替视觉一致性。最终对照见仓库根目录 `design-qa.md`。

后续反馈一并纳入：修复视角和底部四项入口的负宽度文字区域；透明边框采用真实环形网格；两套界面画布按宽度统一缩放，16:10 不再挤压顶部时间栏。世界频道回复采用 Lucide Reply 透明图片，紧接消息最后一行，保留原 NPC 的回复目标。图标来源与 ISC 许可保存在 `native/ArtSource/ui-reference/`。

天气排查发现新玩法没有天气状态，旧世界的空轮询还会清除显示数据。恢复方案在世界服务中保存并推进原天气演算，提供同源风向、雨量、闪电、遮雨、淋湿及环境音投影；Unity 直接消费该投影，旧轮询不再覆盖它。既有存档在原有时间增加天气字段，保留人物和物资。天气适配置于世界服务层，动作执行器、模型训练引擎和已发布权重保持当前校验绑定。
