# 统一游戏界面（2026-10-18）

本次依据用户确认的整屏设计稿实施，当前目录为 `ai_control_games_unity`。Unity 是唯一修改的客户端。

## 结果

- HUD 与管理窗统一为 1920×1080 参考尺寸、相同缩放规则；普通文字 14–16，主标题不超过 20。
- 日期、时段与时刻横排，暂停与倍速紧随其后。频道改为横排筛选与较紧凑的高度。
- 四个玩法入口共用贴底工具栏，距画面底边 10；具有图标、选中和悬停反馈。
- 横向管理窗保留固定导航；制作、人物与营地页采用独立滚动的列表和详情。
- 制作详情展示当前规则配方、领主实际材料成本与工作时间、扣除预留后的可用库存、缺口、工位与解锁条件。操作固定在滚动区域外，宽 156。
- 日常轮询不再伪装成“正在提交”，也不再阻挡可安排的制作命令。所有提交继续由原服务校验和执行。
- 围栏升级归营地页，装备和交接归人物页；协作条款、状态与事件转为面向玩家的文字。
- 设置窗口显示时隐藏新玩法角色标签；保留原地图、中文品牌、玩法、存档与模型的权威边界。
