# 遇阻绕行与模型更新（2026-10-18）

## 根因及分工

原人物移动在同伴挡路时返回 false，使采集/入库立即失败；原动物执行器在直接迈步受阻后仅增加 blocked 并再次推理，同一目标可能反复入选。此前修改暂停状态和任务唤醒不能替代实际避障。

MLP继续选择工作、生存和战斗目标。新增共享局部移动控制器在每个权威步内测试安全转向，保持短期绕行侧向，避免左右抖动；所有候选移动段仍接受地图和实体碰撞检查。人物使用整段到身体的最小距离防止穿人，重叠初态只允许逐渐分离。无可行方向时保持原位并清除旧路线，下次按当前情况重规划；动物同时反馈 blocked 并重新决策。没有修改地图、地形、场景或绕过碰撞。

共享移动执行规则进入人物与动物的来源哈希，两套模型均真实重训，未只修改报告哈希。输入维度不变；不将局部转向规则冒充神经网络直接输出。

## 九人运行状态大小

客户端首次长制作探针超时，不能当作通过。CPU采样显示大量时间消耗于整个世界的重复JSON复制；移动产生的旧观察在原720秒保留期内不断增长。正式宿主现在把10秒前不再需要的运行细节事务归档到SQLite；保留最近事件、进行中工作、有效关系/目标/契约依据以及当前实体认知。归档写入失败不会先删内存；操作代次和过期命令边界仍生效，用户设置不变。

这是宿主运行数据保留策略，原离线执行器和训练样本的物理语义没有改变。短会话归档、活动任务、社会依据及写入失败回滚有专门测试。138项相关测试通过。九人240步独立采样p50约53ms、p95约159ms，不能据此承诺所有长期场景均达到固定实时预算。
