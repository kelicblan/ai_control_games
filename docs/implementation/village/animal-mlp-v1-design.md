# 动物专项 MLP v1 设计草案

本稿为2026-10-18用户已批准的六种动物专项方案。下述“当前代码事实”保留设计前基线；实际训练、接入与验收进度以同目录`animal-mlp-v1-report.md`为准，不将资源交付记作行为交付。

## 当前代码事实

`native/AnimalAssetSources/six-animal-structure-audit.json`记录熊、野猪、鹿、野鸡、兔子、老虎六套带骨骼资源，具备Idle/Walk/Run/Attack/Hurt/Death动画。`src/games/camp/world/ecology.ts`的权威Species类型目前只有兔、野鸡、野猪、老虎四类；`wildlife.ts`主要用固定距离阈值决定游走、逃跑和冲撞，没有饥饿驱动的完整捕食链，也没有动物专项MLP。新村寨战斗当前以袭击狼为对象，不能当作六种野生动物已与人类战斗接通。

## 建议结构

独立的Animal策略族，不复用人类Life/Tactical权重，也不默认给每个物种各训练一套网络。六物种共享主干，输入物种、体型、食性和个体状态，分生活决策与战斗决策两个头；必要时在同一契约下将两头导出为独立权重。先训练生活，再训练包含猎物、掠食者和人类的战斗。大模型不参与动物每次移动或攻击。

| 物种 | 日常需求与生态角色 | 受威胁时的候选行为 |
|---|---|---|
| 兔 | 植物采食、休息、警戒 | 躲避、奔逃、回到掩护 |
| 野鸡 | 植物与地表食物、休息 | 躲避、短距离逃离 |
| 鹿 | 植食、饮水、群体警戒 | 警戒、奔逃，近距离必要自卫 |
| 野猪 | 杂食、采食、休息 | 逃离、受伤或近距离反击 |
| 熊 | 杂食、采集与机会捕食 | 回避、不利时撤退、必要反击 |
| 老虎 | 搜索猎物、潜近、捕食、休息 | 追击、攻击、受伤撤退 |

上述是建议的角色约束，不是已完成的平衡数值。捕食对象、威胁关系、攻击范围、速度和代价必须进入可审阅的物种/食物链配置，不能简单让所有动物互相乱打。已有夜袭狼保留自己的袭击日程与阵营规则，后续通过统一战斗接口交互。

## 权威状态和决策边界

动物状态至少包含身份、物种、位置、生命、体力、饥饿/口渴、警觉、冷却、栖息区域和有限记忆。观察只包含感知范围内的食物、水、猎物、掠食者、人类、遮蔽物及最近受伤/追猎证据。候选动作为移动、探索、采食/进食、饮水、休息、警戒、躲藏、逃跑、潜近、追逐、攻击、防御、脱离战斗及返回栖息地。

MLP只排序当前合法候选。寻路、食物消耗、体力代价、命中、伤害、冷却、死亡和尸体掉落由同一权威规则执行，并进入SQLite；不允许模型直接改HP、瞬移、凭空获得食物或依赖镜头是否看见决定生死。远处可降低决策频率，但必须保持可恢复的逻辑时间。

动物与人类共用目标、碰撞、射程、伤害、掉落与战斗事件契约。人类猎捕必须真实经历发现、靠近/追逐、攻击、动物逃离/反击、击杀和搬运，不通过替换动画或直接增加肉类库存完成。动物不读取玩家背包等隐藏事实。社会化系统可读取“谁狩猎、谁受伤、谁分得食物”等真实事件，动物自身无需生成聊天。

## 训练与验收

1. 先补齐六物种的持久化状态、食物/水源、合法动作、真实规则教师和运行夹具，接入正式村寨快照与现有模型动画。保存现有四类旧状态，使用显式版本迁移。
2. 采集真实执行轨迹训练生活头：寻找食物、水、休息和避险。奖励以实际生命、需求满足、有效采食和能耗为依据，防止原地刷奖励、无限采食或永久躲藏。
3. 加入真实捕食与猎捕，训练战斗头并进行受控对抗。失败轨迹保留，不伪装成成功样本；不能把“总能杀死人类”作为统一目标。
4. 按整地图/种子拆分训练、验证、冻结测试。分别报告六物种存活、饥饿、采食、捕食/逃脱、人类猎捕/受伤、非法动作/卡路、种群与资源平衡，以及CPU推理开销和原生帧时间。
5. 验证动物对食物、距离、遮挡、受伤、武器和人类追猎的响应，覆盖同屏/离屏与存档重载。最后通过正式Unity画面确认六种动物确实在执行这些动作。

动物资产数量、教师一致率、脚本通过率、运行生存率和原生表现分开报告。若共享战斗/规则变更影响人类v4的引擎来源，必须重新采集/训练或完成明确的兼容验证，不能修改哈希绕过加载检查。

## 与当前界面工作的顺序

先按用户要求恢复并扩展原有HUD：保留原按钮、世界频道、视角、鹰眼、日志和设置，在原有入口增加制作、围栏、协作与装备信息。动物训练是新的专项阶段，本稿作为实施边界与验收依据，不能用替换HUD代替生态玩法接入。
