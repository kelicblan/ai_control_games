# 六物种森林生态与动物专项 MLP v1

## 原因与实现

原来六套动物资源仅完成Prefab/骨骼/动画验证。正式村寨快照没有动物生态字段，旧NativeWildernessView仍读取冻结旧世界的四物种状态，因此不能证明动物出现在正式森林。

新增独立动物规则、共享主干双头MLP、村寨宿主适配和Unity显示器。村寨每100ms推进动物一次；暂停、倍速、离线补算使用同一逻辑时钟。动物SQLite表和村寨保存处于同一事务，不靠镜头驱动生死。旧四物种原始快照仍保存在原迁移归档，未将不匹配新地图的旧坐标当成六物种森林位置。

`export-habitats.py`只读已保存地图场景，提取154棵真实场景树的变换，生成独立动物栖息地配置。实际生成点在树旁可行走、寨外地面，避免随机走到地图边缘；地图场景、网格、树木布局和碰撞导出均未由本任务改写。初始22只：兔6、野鸡5、鹿4、野猪3、熊2、虎2。

动物有饥饿、口渴、体力、生命、感知距离、攻击冷却、有限食物/饮水点、尸体肉量。规则控制移动、射程、消耗、伤害、死亡和掉落；模型排序合法候选。捕食关系由物种配置限定，动物不会无理由主动攻击人类；受猎后逃离或反击。

保留原HUD、世界频道及原猎捕入口，新增动物目标详情。靠近发现后真实追逐/攻击/逃离/反击，取得肉类先随身携带，再用原DEPOSIT动作搬运入库。猎捕与原执行器动作互斥，可取消。人类武器属性通过原combatEntity解析真实装备实例，命中/暴击/伤害复用原属性与持久化随机数。原生回归曾发现把实例ID当原型ID导致装备后无法推进，已用真实制作/装备/追猎回归复现并修复，失败证据保留于slice-de222668-38a3-4ffb-adc8-5e15be59c6ef。

Unity直接加载六套已审核资源，按权威位置和模式驱动Idle/Walk/Run/Attack/Death。树冠密集时提供小型物种标记，不改树木，也不改变攻击遮挡和动物感知。猎捕/受伤事件只有参与者或真实附近可见的人物获得个人证据，可供后续社会决策读取；未声称新增动物触发的在线LLM对话已经逐条验收。

## 训练与验证

- 专项网络：32输入、64/32共享隐藏层、life/combat两输出头，六物种条件输入；人类v4执行器和权重未更换。
- 真实规则执行轨迹90,000条，包含需求、掠食者、猎人伤害、受伤反击和障碍。20训练种子、5验证种子、5冻结测试种子，不以测试结果选择检查点。80轮Adam训练，37,040步，验证选择第70轮。
- 模型SHA256：`49308432a1b45e697b47a5e927a44f0e0d666069c3cc50e4c8de3ecf570b6b92`。
- 动物引擎SHA256：`1dbbf944c1a81a0d1e23aab97c96b338f74a687a54f3dfc5fd98804c382ce5ae`。
- 验证教师一致率：life92.60%、combat85.86%；冻结测试：life92.82%、combat88.76%。这是一致率，不是生存成功率。
- 128组Python/TS推理最大差异`2.8633e-5`。
- 每种策略5个冻结种子，各300秒带障碍闭环：教师合计存活103/110，MLP101/110；两者均无饥渴死亡。教师捕食7次，MLP9次；均有采食、饮水、逃脱与受猎反击。MLP平均每次推理约0.035ms。
- 完整数据/指标：`native/Artifacts/animals/mlp-v1/dataset.json`、`evaluation.json`、`public/models/animal-v1/training-report.json`。

## 验收边界

已通过六物种生成、有限资源消耗、物理碰撞、逃跑方向、确定性重放，以及实际长弓制作/装备后的猎捕、尸体取肉、保存重载测试。原生六物种画面、移动、动画、暂停与SQLite/服务重启通过；证据与正式推广结果补于下方。

这版不是长期种群平衡认证：尚无繁殖/季节迁徙机制；测试中存在正常碰撞阻挡及部分追猎失败，不能用300秒试验保证无限期稳定。动物攻击、尸体、镜头与暂停不绕过权威规则；路线受阻会停止追猎并提示。原存档既有的人口死亡、粮食短缺和地图路线问题不由本任务重置。
