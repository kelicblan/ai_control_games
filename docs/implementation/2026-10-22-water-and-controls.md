# 水系连续性与二维操作修复

村北河流此前只有五个局部控制点，首尾均落在草地。现保留村北及木桥位置，将上游接至山地泉池，下游沿山脊南侧山谷接入既有主河；所有新增道路交点统一生成桥梁，水域与桥梁仍由权威地形提供。增加逐段水路连续性、上游山地归属、下游主河连接与建筑防淹检查。山体精灵为水域留出可见通道。

键盘失效原因：默认上帝视角将 WASD 转成相机平移，并将发给服务端的移动向量清零。现在 WASD 始终发送权威玩家移动并进入跟随；方向键、中键拖动平移相机。右键拖动接入二维平面旋转；方向输入与平移根据相机朝向换算，流式加载范围按旋转后的包围盒计算。Home 恢复朝向并跟随，完整区域视图恢复北朝上。屏幕 UI 保持正向，二维资源不伪装成三维背面视角。

保留暂停、管理窗口与文字输入对移动的阻止；暂停时按移动键显示提示。上帝视角的 W 不再触发旧版采食快捷键。正式操作帮助已同步。

旧档：waterLayoutVersion=1 启动前备份；仅修复新水域上被阻挡的活动角色与动物，清理旧导航与活动任务，不平移村寨、不清空库存、不改历史事件。新档直接使用新水系。

验证：78 项地图及输入检查、21 项 Unity EditMode 检查、TypeScript 检查通过；旧档副本保留人物身份、库存、资源消耗和历史事件，二次重启幂等。实际控制验证通过 Unity Input System 发送输入，在正式服务快照核对坐标变化与相机旋转，结果存于 native/Artifacts/reference-map/water-native.log。本候选仍需用户体验验收，不代表整体设计图完全还原。

持续输入补充：方向心跳改为只查询当前世界标识，避免每次方向包重复生成公开快照；输入有效期为 1 秒，松键／失焦发送零方向，失联自动超时停止。移动输入携带 worldId，旧世界方向包被拒绝。新增真实世界运行回归覆盖延迟、释放、暂停、过期和代际隔离。客户端验证使用持续帧输入并等待权威位移，避免把固定短时间内不足一次世界更新误当作失效；只读诊断计数不写入存档。

最终原生证据：native/Artifacts/reference-map/visual-1792660658795/controls-water.json。权威位置单方向连续移动 2.25 米，右键旋转、暂停停止、窗口阻止旋转、Home 恢复朝向均通过；诊断记录 24 个非零输入、23 次实际移动、0 次输入过期。截图含河源、山谷至主河、整图与旋转后画面。候选清单：water-controls-verified.json。此旧档验证期间最大状态快照间隔约 2.84 秒；不宣称操作延迟已全面优化，世界推进性能仍有改进空间。所有验证使用旧档副本，未替换用户正在运行的存档。
