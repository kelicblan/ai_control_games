# 道路连通与避障修复（候选）

用户截图指出区域干道在村寨中央交叉、穿房、穿山和跨水断开。

原因：原始参考折线直接作为道路，未处理山体与村寨障碍；地表道路判定先于山体；桥梁只按区域河流中心线交点推算，漏掉村北支流及弯曲河岸；区域支路端点未验证用途。

修复：保留参考图大方向与关键目的地，采用确定性地形约束路由连接手绘控制点。区域干道绕开村寨 350 米范围，在南门外 400 米路口汇合；寨内道路接建筑门口。西北矿区和石场使用明确开阔的山谷入口，其余道路绕开山体。区域与本地道路统一扫描完整水域带生成桥面，覆盖所有穿水区间。西侧支路接地图边界，南侧支路回接主路，东北支路通往深林猎场。近远景山体和远景树木留出道路通廊，禁止远景道路覆盖山体地形。

旧存档：启动器先备份，roadLayoutVersion=1 一次性迁移仅把被新地形阻挡的活动角色投影到安全点，取消旧的执行中任务、清除旧导航缓存；不再次平移村寨，不修改库存、角色身份或历史事件。

验证：74 项地图检查通过，新增道路逐 8 米检查（建筑避让、山体避让、地表可走或桥面）及端点用途检查；TypeScript 检查通过；实际旧档副本启动和二次重启通过，库存、10 个角色、资源消耗和历史事件保持。完整原生截图另见 native/Artifacts/reference-map/road-native.log。

范围：这是道路缺陷修复，不代表整张地图达到设计图 100% 精细度。路由保留目的地方向并根据当前权威地形绕行；未将自动检查当作真人画面验收。

原生复查补充：合并命名桥与自动桥的重复几何；桥板先在世界平面旋转，再进行纵向投影，消除板缝与错位。桥面收窄为 12 米、按两岸实际水带加短搭接段计算长度。Unity EditMode 19/19 通过。最终截图目录：native/Artifacts/reference-map/visual-1792644361801。
