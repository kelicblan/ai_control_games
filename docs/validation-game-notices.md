# 统一左下角可关闭提示

2026-10-14。

- 存档连接异常、模型加载失败、音效异常和操作反馈统一由 `GameNotices` 绘制，固定左下角，多条按列排列，逐条提供 X 关闭按钮。
- 同一持续错误被关闭后不因重复轮询或打开设置而重新弹出。错误恢复后若再次发生，重新显示；更换模型也视为新提示。操作反馈每次分配任务产生独立提示，保留原有自动消失时间。
- 关闭只是隐藏提示，不停止重连、重试或模拟。模型设置入口保留。
- 统一提示宽度 360px；较窄桌面窗口将提示提高至任务栏上方，防止遮住底部操作。
- 设置表单内部的校验和状态、人物对白、伙伴请求仍属于各自界面内容，本次统一的是全局悬浮通知。

验证：

- `npm run build` 成功，保留现有包体大小警告。
- 全量单测 53 个文件、525 项全部通过，日志 `data/game-notices-full-test.log`。
- 浏览器回归通过：存档连接异常提示左下角位置、手动关闭、恢复后新异常重新出现；模型失败提示关闭与显式重试。存档场景最初在旧实现中验证失败（左坐标为 380，而非 16），统一组件后通过。
