## 生效范围

开局先读模板，再创建游戏；读取失败时保留旧档，只有用户明确选择才用内置初值开始。设置页保存不修改本局；本局快照进入原存档，读档不重新设置健康、体力、记忆或情绪。自定义角色的人格用于心智评价、模型投影和台词描述。未修改的旧 MLP 投影保留，以免只改体力却改变原有策略输入。

技能是 0..100 熟练度，50 保持原速度；只影响对应动作的工作阶段进度，不改变即时资源、不加速背包返送，不改变休息/进食。技能没有自动成长系统，本次只提供初始值与执行效果。

浏览器实际使用 IndexedDB，保存在同一浏览器、同一站点。SQLite 是已实现的宿主驱动适配器，不是当前网页已启用的 SQLite 数据文件。清除网站数据会清除本地模板；可用 JSON 导出备份。
