# 对话来源图标验证

2026-10-15。地图气泡和正式对话记录中的 NPC 台词前增加来源图标：代码符号表示代码兜底，芯片表示 MiniMind3，星标表示优先模型。悬停和无障碍标签显示来源，优先模型包含具体名称。玩家台词不加 NPC 来源图标。

来源依据实际返回的 `minimind3`、`native:*`、`remote:*` 标识，不依据当前选中的模型或全局连接状态。预生成缓存保存原始模型来源，缓存命中次数单独统计。旧历史中只有 `cache` 的记录无法还原模型来源，显示问号并说明“来源未记录”。

字幕提交保存与文本和显示期限绑定的 `speechOrigin`；代码随后替换文本或更新显示期限后，失效的来源不会继续用于新台词。新字段可选，旧存档仍可读取，字段存在时验证其形状。前端发送 caption 时使用实际来源，世界服务及 SQLite 快照保留它，避免普通气泡统一被记为 MiniMind3。

验证：7 个文件、194 项测试全部通过，包含三类图标、原始缓存来源、旧档兼容、来源失效、三类模型的世界写入与数据库读回、HTTP 服务和客户端测试。`npm run build` 与 `npm run check:npc` 通过。没有重复执行已有三个未解决问题的完整测试集。

浏览器技能启动失败：`privileged native pipe bridge is not available; browser-client is not trusted`。已验证组件输出 SVG、来源类别及可访问标签，但未取得实际画面截图。

在线世界服务必须重启后才加载新的来源持久化逻辑。此前重启操作被自动审批拒绝（`blocked by policy`），本次没有绕过该拒绝；需要手动重启世界服务。

后续补充：世界频道的 NPC 记录行首也显示相同来源图标。记录捕获时复制实际字幕或社交记录的来源，后续模型切换不改变历史记录的标识；代码替换字幕后记录为代码兜底，玩家指令与系统消息不标为模型生成。世界频道深色背景使用更亮的图标颜色。相关 60 项测试及构建通过；实际画面验证仍受上述浏览器桥接错误限制。
