## 已接入的行为

- MLP 保留基础生存、劳动和导航。社会模块维护有收件人的消息、回应和约定；接受有明确地点的邀请后建立权威约定，NPC 通过原有导航前往寨里广场（50，110）。到场依据真实坐标及可通行性，不依据模型自述。
- 生存紧急情况、威胁、手动安排、暴风雨或超时取消约定；死亡 NPC 和玩家不会被自动冒充发言。到场后仍未等到回应不能记为成功交谈或增加关系。
- 玩家自由文本入口关闭，服务端生成候选项并审核。只提交批次 ID 和选项 ID，按消息消费一次；生成、刷新候选项均不发送玩家消息、不建立约定。
- “更换一批”使旧批次失效，以上一批文本为上下文生成新候选项；3 秒内重复刷新被拒绝，按钮请求期间禁用。模型完全重复或生成/审核失败时提供安全退出选项。
- 模型文本、社会意图及认知 appraisal 都有发布门禁。词库中的命中片段显示为 `**`；不安全整条意图被丢弃。旧历史首次显示前审核，版本变化使候选项与记忆缓存失效。
- 状态持久化于原有 SQLite 快照事务；重置、世界代次或模型设置变化使迟到结果失效。客户端不能使用旧 NPC 文本提交接口绕过审核。

## 独立审查与实施取舍

独立只读审查发现的三项重要问题均修正：认知结果绕过门禁、约定生命周期自动替玩家/死者发言、历史记忆缓存绕过词库更新。另修正未回应也算成功交谈的问题，红绿测试见 `.social-silent-red.log` 与 `.social-lastfix.log`。

- 保留原脏工作区并建 `codex/social-agency-moderation` 分支；不提交已有改动。代价是回滚须逐文件核对，不能整库 reset。
- 复用已配置模型作为语义审核后端，保持可替换的 `JsonGenerator` 边界。代价是较弱模型会误拒绝并频繁兜底；尚未接入独立专业审核服务。
- 首期会面地点只开放广场，未实现自由地点或复杂时间排程；改期/拒绝结束当前邀约，不伪造未来必然赴约。
- 历史内容在服务端投影时重新审核遮罩，保留原有用户存档与备份；新认知在接纳前审核。不会自动清除旧备份。
- 细分爽约惩罚、全场景帧率观察、写入每个边界的崩溃注入，以及真实模型完整闭环仍是待验收项，未把计划全部勾选完成。
