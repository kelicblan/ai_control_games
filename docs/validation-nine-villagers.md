# 九位属民验收

九位角色为阿壮、小米、老周、林枫、阿野、铁生、阿绫、小满、沈砚。新人具有独立九维人格、任务模型投影、初始身体参数、头像、场景配色与轮廓、声音及第 6–9 座住房。

## 验证结果

- 最终相关 9 个测试文件合计 176 项通过，见 `data/nine-villagers-final-tests.log`。覆盖人格实际行为差异、台词、社交、自定义性格、五人/三人历史存档与设置迁移、床位、任务站位、世界频道。
- 场景与音效等附加验证 66 项通过；人格核心及社交验证 45 项通过。上述数量有重复，不累加为测试总数。
- `npm run build` 成功，类型检查通过，离线缓存清单已更新，日志 `data/nine-villagers-build.log`。既有大分块体积提示仍存在。
- 数据库的 13 份各玩家最新快照均能恢复为合法九人状态；未执行世界重置。
- 一致性备份：`data/world-before-nine-villagers-20261015.sqlite`。
- 固定种子 17、cozy、规则策略模拟 600 秒（一个游戏日），所有采样存档合法、九人均存活，模型输入均为合法有限数值。原始数据见 `data/nine-villagers-simulation.json`。仅验证此配置与时长，未以此宣称长期生存平衡；该样本末尾食物为 0，个别角色饥饿较高，经济与策略参数未因此擅自改动。
- 浏览器实测九个头像、数字键 9 选中沈砚，头像栏底边 370px，世界频道顶边 477.6px，互不遮挡；视角与资源工具条顶边均为 12px。
