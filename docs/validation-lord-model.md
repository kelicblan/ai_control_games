# 修真者领主模型与动画

2026-10-15。使用用户确认生成的 Tripo 修真者模型替换领主外观。

- 游戏资源：`public/assets/models/lord/model.glb`，28,776 三角面、3 张内嵌贴图、82 个骨骼关节。
- 动画：本地原创骨骼关键帧 `Idle`（3.2 秒）和 `Walk`（0.88 秒），循环连续、无水平根运动。基础迈步、摆臂、呼吸和衣摆摆动，不包含布料物理。
- 制作脚本：`node scripts/animate-lord.mjs`。输入为项目上级模型目录中的已绑骨 GLB；保留原始模型与贴图。
- 加载后替换旧人物的躯干和双腿，统一高度至 7.8 世界单位、脚底归零、将源模型 +X 朝向转换为游戏 +Z。保留玩家标记和脚底光环。
- 真实位移触发行走，松键返回待机，暂停冻结动画；加载失败保留旧人物。场景退出时停止混合器并释放骨骼纹理，异步返回的模型也会释放。
- 验证：5 个相关测试文件、14 项测试通过；`npm run build` 通过（已有的大包警告仍在）。
- 实际游戏验证：资源加载、WASD 触发 Walk、松键回到 Idle、上帝视角切换通过。记录见 `docs/lord-ui-verification.json`。独立模型预览已检查正面、侧面。
- Tripo 动画 API 返回 1004，失败任务均退款；本地动画没有额外 API 费用，余额 230、冻结 0。
