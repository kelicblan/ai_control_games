# 2026-10-16 NPC 工作与对话关联修复

## 实际采样

从现有世界的 HTTP 快照连续采样三次，间隔十秒，保留在 `.npc-dialogue-live-before.jsonl`。同时读取当前 SQLite 快照核对社会线程与消息。

- 原始天气请求「这天气让我不太踏实，能安排在近处或先躲躲吗？」被通用性格表达覆盖成「这活又累又烦，先找别人。」
- 已发生的线程发言再次交给模型生成社会消息，普通分工/问候被改成 `invite`；模型失败则统一变成「这次先不聊了，改天再说。」
- 社会服务每隔 45 秒尝试随机找同伴去广场聊天，不需要任何工作事件。
- 回复上下文缺少完整回复链、双方背包与任务阶段；模型生成期间工作变化也未重新校验。

## 修复

- 社会服务只处理实际诉求/发言和待回复消息，移除随机定时邀约；模拟层移除无事定时 checkin，玩家仍可主动交谈。
- 原有社会线程按原话进入消息链，保留目标与明确邀请标记，不生成第二个不同版本。
- 初始诉求和安排回应保持具体主题，性格只修饰语气，不覆盖需要或已选择的安排。
- 回复携带最多七轮父消息、双方当前任务、采集阶段、背包、地点、进度、村寨事实、口粮与待兑现承诺。
- 非邀约问题不能被转换成邀约/接受约会；原句复读采用当前工作描述兜底。发布时检查任务/阶段/背包是否变化，变化则使用最新真实任务描述。
- 不增加模型对资源或劳动结果的直接写权限，实际执行仍在模拟中。词库替换规则保持不变。
