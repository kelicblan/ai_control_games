# 世界频道与顶部视角工具条验收

- 视角工具条与资源工具条顶部均为 12px（1280×720 桌面浏览器实测）。收紧较窄桌面窗口的资源栏，工具条不互相遮挡。
- 左下固定频道统一显示 NPC 台词、社交记录、玩家指令、世界活动以及连接、模型、音效和设置报错。NPC 气泡和原有社交窗口保留。
- 消息按类型配色，新增消息滚动到底部，最多保留最新 100 条；重复快照不重复写入，持续故障只记录一次，恢复后再次失败可以再次记录。
- 浏览器实际点击“收集木材”，原任务栏切换为收集木材，频道新增领主指令和系统反馈，达到 100/100 条；滚动到底部误差小于 1px。
- 相关 4 个测试文件共 30 项通过：world-channel、world-client、npc-settings、npc-settings-camp。
- `npm run build` 通过，离线缓存清单更新；仍有既有的大分块体积提示。
- 截图：`docs/screenshots/world-channel-20261015.png`。
- 频道是当前页面的展示历史，不进入任务决策和世界模拟，不新增数据库消息表。重新打开时可从存档中仍保留的活动和社交记录重建消息。
