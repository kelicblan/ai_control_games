## 首轮付费计划

输入为父目录“模型/模型原图”中的领主宅.png、属民屋.png、围栏和寨门.png、瞭望塔.png。模型别名tripo-v3.1，实际请求v3.1-20260211。每项调用一次POST /v3/generation/image-to-model，texture=true、pbr=true、texture_quality=detailed、geometry_quality=detailed；领主宅face_limit=80000，其余50000。原图含背景，输出必须检查是否混入背景与周围建筑；不合格结果不自动重新扣费生成。

每项预计30基础+10高清贴图+20高清几何=60积分；4项共240。没有添加付费转换、分割、绑定或动画。失败任务按服务规则退还，成功但不满意的任务仍需计入成本。最终以各任务credits_consumed为准。

交付源文件目录native/ArtSource/reference-sample/tripo-out/<name>-<id>/，预期保留GLB、预览、任务记录；CLI dry-run的deliverables字段为空，实际下载文件需进一步核实。原始生成文件保持可追溯；通过检查后才导入Unity独立样板资源目录。

## 后续执行与验收

1. 检查四项预览和真实网格，核对背景混入、门洞、台阶、支撑和建筑背面；必要时准备隔离参考图，额外付费步骤另列。
2. 建立独立样板布局配置，复用人物与地形采样，设置建筑比例、河岸、通路与参考镜头；避免修改现有玩家存档。
3. 修整模型，独立处理门、碰撞、台阶和屋顶。不能用整栋实心碰撞盒封死门洞。
4. 等现有构建释放工程后，构建隔离样板，验证领主行走、寨门、建筑入口、岸边和桥头通行。
5. 保存真实游戏截图及固定镜头参数，对照参考图记录差异。全景轮廓、近景结构、通行与性能分别验收；构建通过不代表视觉通过。
