# 森林动物模型样板（2026-10-19）

当前提供老虎、熊、野猪、野鸡、兔子、鹿、狼七种模型、蒙皮骨骼和 Unity Prefab。
运行资源位于 `../CampMind.Unity/Assets/CampMind/Content/Animals/`。

每种动物的 `*Rig.glb` 保留原始骨骼模型，`*Actions.glb` 包含动作。Unity 使用同目录的 Prefab、Animator Controller 和 `.anim` 文件。
统一状态名为 `Idle`、`Walk`、`Run`、`Attack`、`Hurt`、`Death`；野鸡另有 `Flap`。待机、移动、振翅循环，攻击、受击、死亡不循环，关闭 Root Motion。后续表现层可通过 `Animator.CrossFade` 选择状态。

老虎 Walk 为 Tripo 四足专用动作。其余动作是本地骨骼动作原型，尚需逐物种精修脚底接触、跳跃、扑咬、爪击、顶角等表现，不能视为最终战斗动画。
野猪、野鸡未通过 Tripo 自动绑定检查，保留原始生成结果，改为本地绑定，无额外 API 消耗。
狼的生成结果混入一块独立的小动物网格，已本地清理。狼使用清理后的 GLB 和 Prefab；原始 FBX 仅归档于 `tripo-out/wildlife-wolf-convert-21d7bc0f/`，不作为游戏运行资产。清理和动作补齐均无新增 API 消耗。

Prefab 默认面朝 Unity +Z，脚底归零，按长轴估算体型：老虎 3m、熊 2.2m、野猪 1.6m、野鸡 1m、兔子 0.45m、鹿 2m、狼 1.7m。尺寸属于首版美术配置，含尾巴、鹿角等外形，不代表精确生物测量。
