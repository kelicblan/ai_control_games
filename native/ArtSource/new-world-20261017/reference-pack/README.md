# 国风奇幻村落世界美术参考图包

本包收录23张原始图片，按用途整理文件名，图片字节与来源完全一致。建模风格以原图的国风奇幻、风格化半写实3D与手绘材质为基准。

## 目录

| 目录 | 数量 | 用途 |
| --- | ---: | --- |
| `01_master_map` | 1 | 世界地图原图，整体布局与风格总基准 |
| `02_style_references` | 5 | 用户上传的色彩、空间与意境辅助参考 |
| `03_map_variants` | 3 | 两张绘画感地图与一张像素风备选归档 |
| `04_model_references` | 14 | 建筑、设施、地形、山体与树木的单件建模参考 |
| `05_documents` | 2份文档 | 18页说明的可编辑Word版与阅读用PDF版 |

`asset_manifest.json` 记录每张图片的包内相对路径、来源文件名、中文名称、分类、像素尺寸、字节数、SHA-256、用途与参考优先级。

## 基准关系

P0原图决定整体风格、布局和层级；P1单件图片补充对象造型；P2上传风格图辅助色彩与氛围；P3地图变体保存探索过程。局部细节与总体关系冲突时，回到P0原图核对。参考图01至05分别对应上传文件编号200、201、202、203、199。

14张单件图片用于图生3D输入或人工建模参考，未包含可直接交付的3D模型。生成后仍需检查结构、比例与网格，并按项目需求处理材质、碰撞体、LOD及树木风动画。

## 文件完整性

图片总量：23张；图片总字节数：49,246,226 bytes。已逐项比对源文件与副本SHA-256，23/23一致，全部源图片均已纳入。所有图片保留原始编码与分辨率，未裁切、放大或重新编码；上传截图自带的界面内容也保持原样。

## 阅读与使用

先阅读 `05_documents` 中的说明文档，再结合原图确定参考相机、村寨布局与灰盒。文档包含统一风格、14类资产制作分工、补图与接口修正、Three.js接入、还原边界、分阶段验收及费用控制。

现有图片不能唯一恢复完整三维几何。原图定义可见布局；背面、遮挡处、尺度与通行空间需要补全。文档中的费用演算与视觉验收数值均明确标为建议或假设，不是已经完成的三维制作或性能结果。

所有图片保留当前实际分辨率。此包不把1672×941等文件标为原生4K。
